二、跟AI协作的正确姿势CHAPTER · 章节内容

📌 本节要点
✦ 2026年，学编程的正确方式是跟AI协作：✦ 那是20年前的方式✦ 1. 读 — 逐行看，不懂就问AI"这行是什么意思…

很多人学编程，上来就背语法、记函数名、默写格式。那是20年前的方式。

2026年，学编程的正确方式是跟AI协作：

Code

你描述需求 → AI写代码 → 你看懂代码 → 你修改代码 → 你独立写代码

关键认知：AI不是替你写代码，是教你写代码。

就像学开车，教练可以帮你打方向盘，但最终你要自己握住它。AI就是那个教练。

每次AI给你代码，你要做三件事：

  1. 读 — 逐行看，不懂就问AI"这行是什么意思"
  2. 改 — 改个参数试试，看输出变不变，建立直觉
  3. 写 — 关掉AI，自己默写一遍，写不出来就回去再读

能默写出来，才算学会了。 记住这个标准。

练习4：故意写错

Python会报错。别怕报错，报错是Python在跟你说话，告诉你哪里不对。试着读懂错误信息，修好它。

06
六、进阶：用变量记住名字CHAPTER · 章节内容

📌 本节要点
✦ 现在试试这个新写法：✦ 输出：你好，小明✦ 每改一次，输出就跟着变——这就是变量的用处

现在试试这个新写法：

Code

name = '小明' # 用 name 这个名字，记住 '小明' 这个值

print(f'你好，{name}！') # 花括号 {name} 会被替换成 name 的值

输出：你好，小明！

逐行解释：
- name = '小明' — 创建一个"变量"叫 name，把 '小明' 存进去。就像给一个盒子贴上标签，里面放一张写着"小明"的纸条
- f'你好，{name}！' — 前面加 f 表示这是"格式化字符串"，花括号 {name} 会被替换成变量的值

试着改改看

把 小明 换成你的名字，运行看看。再改成你朋友的名字。每改一次，输出就跟着变——这就是变量的用处。

Code

name = '小红'

print(f'你好，{name}！') # 你好，小红！

print(f'{name}在学编程') # 小红在学编程

print(f'{name}加油！') # 小红加油！

💡 你看，只改了一处 name = '小红'，三行输出全跟着变了。 如果没有变量，你得改三个地方。

CHAPTER
07
七、让AI带你做更酷的事CHAPTER · 章节内容

📌 本节要点
✦ > 你："for i in range100 是什…✦ 对话1 — 让AI写程序：✦ > 你："帮我写一个程序，输出我的名字100次"

现在你已经理解了 print 和变量，试试在Cline或MiMo里做这些对话：

对话1 — 让AI写程序：

你："帮我写一个程序，输出我的名字100次"

AI可能会写：

Code

name = '小明'

for i in range(100): # range(100) 表示"重复100次"

print(f'第{i+1}次：{name}')

看不懂？没关系，继续问AI：

你："for i in range(100) 是什么意思？为什么 i+1 而不是 i？"

对话2 — 让AI改程序：

你："把名字改成小红，改成只输出10次"

对话3 — 让AI教你新东西：

你："我想让输出的内容带颜色，怎么做？"

这就是跟AI协作编程的循环：描述需求 → 理解代码 → 修改代码 → 再描述新需求。

每循环一次，你就多懂一点。几十次循环之后，你就不需要AI了。
