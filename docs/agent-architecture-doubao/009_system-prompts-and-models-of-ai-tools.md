## 1. 项目概述与定位

- **项目名称**：System Prompts and Models of AI Tools（作者 x1xhlol）
- **GitHub 地址**：https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools
- **Star 数**：约 143,581（批次数据）；语言字段为空（以 Markdown 为主）
- **主要语言**：Markdown（提示词文本汇编）
- **一句话定位**：公开搜集整理的主流 AI 编码/对话工具（Augment Code、Claude Code、Cluely、Cursor、Devin 等）的**系统提示词(system prompts)与所用模型清单**汇编。
- **目标用户/场景**：研究各家 agent 产品提示工程设计、做提示词逆向学习的开发者。
- **成熟度**：随各家产品更新持续收录，社区 star 高，属知名"逆向资料集"。

> **关键定性：这不是可运行的 agent 系统**，而是提示词资料汇编（部分来自泄露/逆向）。无编排逻辑、无工具调用机制、无运行时。第 6/7/8 章按规范标注"不适用"。本次其 README 抓取命中安全策略（内容敏感），未逐篇读取，结论据批次数据与项目公开性质。

## 3. 系统架构分析

- **编排模式**：**不适用**。无 ReAct / Plan-Execute / Multi-Agent / Workflow 编排——它只是别人 agent 的"配置快照"。
- **核心组件**：无。它是**被研究对象的文本**，不是系统。
- **数据流**：不适用。
- **对 agent 开发的价值**：它是**提示工程语料**——可以横向对比 Claude Code/Cursor/Devin 等如何写 system prompt（角色设定、工具使用规范、安全约束、输出格式）。

## 4. 功能拆解

- 核心功能：按工具分类的 system prompt 全文 + 模型/参数清单。
- 无工具系统、无前后端。
- 参考价值：提示词模板库，供学习与改写。

## 5. 技术亮点与优势

1. **一手对比语料**：把多家头部 agent 的系统提示词放一起，是研究"产品级 prompt 设计"的稀缺材料。
2. **覆盖广**：编码工具、对话工具均收录。
3. **学习价值高**：可从中提炼通用的 system prompt 结构（角色/能力/约束/安全/格式）。

## 9. openmate 可借鉴点【重点】

- **P1｜system prompt 结构模板**：从这些一手案例中提炼通用骨架（角色定位 → 能力清单 → 工具使用规范 → 安全/禁忌 → 输出格式 → 示例），作为 openmate 系统提示的撰写模板。预期收益：站在头部产品的 prompt 设计肩膀上。
