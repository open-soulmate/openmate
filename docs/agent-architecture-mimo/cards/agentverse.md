# AgentVerse

## 一句话定位
OpenBMB 多 Agent 平台：自定义 Agent 团队完成协作/竞争任务，偏研究与沙盒。

## 核心架构（4点）
1. **自定义 Agent**：角色、工具、记忆可配置
2. **多智能体沙盒**：在模拟环境中协作/竞争完成任务
3. **协作协议实验场**：适合研究分工与沟通效率
4. **与 CAMEL/ChatDev 同属清华系生态**：强调角色扮演与社会性

## 稳定性亮点
- 研究导向，场景可复现脚本化
- 强调 Agent 间通信结构而非单点性能
- 生产部署与权限模型相对较弱，需自建

## 对 openmate 借鉴
1. **角色+工具绑定**比「万能 Agent」更可控
2. **通信协议要显式**：谁在何时对谁说话，避免隐式共享上下文爆炸
