# FastGPT

## 一句话定位
AI Agent 构建平台：开箱即用数据处理与模型调用，Flow 可视化编排复杂工作流。

## 核心架构（4点）
1. **应用编排**：Agent Skill + 对话/插件工作流 + RPA 节点 + 双向 MCP
2. **知识库**：多库复用混用、chunk 级修改、混合检索+重排、API 知识库
3. **调试能力**：单点搜索测试、引用可改删、完整调用链路日志、应用评测
4. **运营能力**：免登录分享、iframe 嵌入、对话标注、运营日志

## 稳定性亮点
- Docker 一键部署 + Sealos 云部署
- FastGPT Open Source License：可商用后台服务，禁止 SaaS 转售
- 与 AI Proxy（模型聚合负载均衡）深度集成

## 对 openmate 借鉴
1. **Flow 可视化 + 调试链路**：生产级 Agent 平台必须有可追溯的调用日志
2. **知识库 chunk 级管理**：入库后可修正/删除单条，避免"垃圾进垃圾出"
