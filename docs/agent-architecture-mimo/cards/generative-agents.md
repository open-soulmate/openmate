# Generative Agents

## 一句话定位
斯坦福经典论文实现：可信人类行为模拟小镇，多 Agent 记忆/反思/计划与社交。

## 核心架构（4点）
1. **记忆流**：自然语言记录 + 重要性/相关性检索
2. **反思**：周期性从记忆抽象出更高层见解
3. **计划**：日程到具体动作的分解
4. **社交传播**：信息在 Agent 网络中扩散

## 稳定性亮点
- 奠定「记忆检索 + 反思」范式，后续大量系统引用
- 行为可解释：决策对应可读记忆条目
- 计算与成本高，偏研究沙盒

## 对 openmate 借鉴
1. **记忆要有重要性衰减与反思摘要**，而不是无限追加 chat log
2. **计划生成要落成可观察日程/待办**，用户能纠正
