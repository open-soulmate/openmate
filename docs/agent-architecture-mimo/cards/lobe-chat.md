# LobeChat / LobeHub

## 一句话定位
把 Agent 当作工作单位：招聘、调度、汇报整个 AI 团队，人与 Agent 共同进化的工作空间。

## 核心架构（4点）
1. **Operator 层**：统一管理所有 Agent，IM Gateway 让 Agent 出现在已有聊天工具中
2. **Agent Builder**：描述需求即自动配置 Agent，10000+ Skills/MCP 插件库
3. **Agent Groups**：多 Agent 并行协作、共享上下文的 Pages、Schedule、Project、Workspace
4. **White-Box Memory**：结构化可编辑的个人记忆，持续学习工作习惯

## 稳定性亮点
- 完善的 UI 组件生态（@lobehub/ui/icons/tts/lint）
- Docker/Vercel/阿里云一键部署
- 插件三阶段演进：分离→安全稳定→高级定制

## 对 openmate 借鉴
1. **Agent Groups + Schedule**：多 Agent 并行 + 定时运行，是"7×24 运营"的核心
2. **白盒记忆**：可编辑的结构化记忆比黑盒向量更可控、更可信
