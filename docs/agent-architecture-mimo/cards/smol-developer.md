# smol developer

## 一句话定位
极简「规格→代码」AI 开发者：用短 prompt 让模型生成并迭代整个小项目骨架。

## 核心架构（3点）
1. **单入口 prompt**：用户描述 → 生成文件树与代码
2. **循环修补**：根据错误/反馈再生成
3. **人机共驾**：生成结果由人审查落地，不追求全自动

## 稳定性亮点
- 代码面小、概念简单，易读懂易改
- 适合启发「最小可行 Agent」而非生产平台
- 大项目上下文与正确性保障有限

## 对 openmate 借鉴
1. **先做最小闭环**：spec → scaffold → test → 修，避免一上来大而全
2. **生成物必须可落盘审查**：比聊天里贴代码更可协作
