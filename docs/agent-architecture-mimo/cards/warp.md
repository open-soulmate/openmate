# Warp

## 一句话定位
AI 原生终端：把命令执行、块输出与 Agent 工作流统一到可协作的现代 shell 体验。

## 核心架构（4点）
1. **块化终端**：命令与输出成块，可分享、可搜索、可复用
2. **Agent Mode**：自然语言 → 执行计划 → 确认后跑命令
3. **Input/Output 分离 UI**：减少滚动找历史的脆弱操作
4. **协作与驱动器**：团队共享命令、notebook 式流程

## 稳定性亮点
- AI 建议仍以「用户确认执行」为主，降低误跑风险
- 块结构让失败输出可精确定位，而不是整屏日志
- 云端/团队能力与本地终端解耦

## 对 openmate 借鉴
1. **命令执行做成 block + 确认门**：个人助手 shell 工具必须 preview 命令再执行
2. **输出结构化成块**：便于引用、重试与审计
