# AstrBot

## 一句话定位
开源全能 Agent 聊天机器人平台，深度集成主流 IM（QQ/企微/飞书/钉钉/Telegram 等）。

## 核心架构（4点）
1. **多平台适配**：QQ/OneBot/Telegram/企微/飞书/钉钉/Slack/Discord/LINE 等官方维护
2. **Agent 能力**：LLM 对话、多模态、MCP、Skills、知识库、人设、自动上下文压缩
3. **平台集成**：支持接入 Dify/阿里云百炼/Coze 等 Agent 平台
4. **插件市场**：1000+ 插件一键安装

## 稳定性亮点
- Agent Sandbox：隔离安全执行代码/shell，会话级资源复用
- WebUI + Web ChatUI 双界面
- 部署方式多样：uv 一键/Docker/桌面应用/Launcher/宝塔/1Panel/CasaOS

## 对 openmate 借鉴
1. **IM-first 设计**：Agent 能力绑定到用户已有聊天入口，而非要求打开新 App
2. **Agent Sandbox**：代码执行必须隔离，是 IM 场景的安全底线
