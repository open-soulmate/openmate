# CAMEL

## 一句话定位
探索 Agent 缩放定律的开源社区框架：支持百万级 Agent 模拟、数据生成、任务自动化与世界模拟。

## 核心架构（4点）
1. **ChatAgent**：核心 Agent 架构，支持工具、记忆、RAG
2. **Agent Societies**：Role-Playing、Workforce 等多 Agent 协作模式
3. **Data Generation**：CoT/Self-Instruct/Source2Synth/Self-Improving 数据生成流水线
4. **百万级模拟**：OASIS 项目支持 1M Agent 社会模拟

## 稳定性亮点
- 设计四原则：Evolvability/Scalability/Statefulness/Code-as-Prompt
- 100+ 研究者社区驱动，多篇顶会论文
- Apache 2.0 许可，PyPI 包 `camel-ai`

## 对 openmate 借鉴
1. **Code-as-Prompt**：代码和注释本身就是 Agent 的提示词，写清楚代码即写清楚 prompt
2. **合成数据生成**：Agent 框架可反哺训练数据，形成飞轮
