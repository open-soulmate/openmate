# ChatDev 2.0（DevAll）

## 一句话定位
零代码多 Agent 编排平台：从虚拟软件公司演化为通用多 Agent 工作流平台，YAML 配置即运行。

## 核心架构（4点）
1. **YAML 工作流**：定义 Agent、工作流与任务，无需编码
2. **可视化画布**：拖拽设计节点、配置参数、定义上下文流
3. **Python SDK**：`run_workflow()` 程序化执行，获取结果
4. **OpenClaw 集成**：可通过 OpenClaw 自然语言创建/调用 ChatDev 工作流

## 稳定性亮点
- 1.0 经典版保留于 `chatdev1.0` 分支（虚拟软件公司范式）
- Puppeteer 式 RL 编排研究（NeurIPS 2025）
- MacNet DAG 拓扑支持千级 Agent 协作

## 对 openmate 借鉴
1. **YAML 即工作流**：配置文件驱动多 Agent 编排，比纯代码更易传播
2. **1.0→2.0 演进路径**：从垂直（软件公司）到通用平台，保留旧版分支供学习
