# Khoj

## 一句话定位
个人 AI 第二大脑：从本机个人 AI 平滑扩展到企业级云端，支持任意 LLM + 文档语义检索 + 自动化研究。

## 核心架构（3点）
1. **多入口**：Browser/Obsidian/Emacs/Desktop/Phone/WhatsApp 统一访问
2. **自定义 Agent**：可配知识、人格、聊天模型与工具，承担特定角色
3. **自动化研究**：定时任务、个人 newsletter、智能通知推送至邮箱

## 稳定性亮点
- 支持本地 LLM（llama3/qwen/mistral）与云端 API 混合
- 文档类型覆盖广：PDF/Markdown/Notion/Word/org-mode/图片
- 自托管始终开源，可私有运行

## 对 openmate 借鉴
1. **多端一致性入口**：同一 Agent 能力覆盖 Web/编辑器/桌面/手机，降低切换成本
2. **自动化研究闭环**：不只是问答，而是"监控源→变化时主动推送"
