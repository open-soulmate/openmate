# Mind2Web

## 一句话定位
真实网站多领域网页 Agent 数据集：通用 web 智能体的离线训练与评测基准。

## 核心架构（4点）
1. **大规模真实站点任务**：跨领域、跨网站
2. **演示轨迹**：人工标注动作序列
3. **HTML 观测空间**：强调在庞大 DOM 中定位与操作
4. **泛化评测**：新任务/新站点上的迁移能力

## 稳定性亮点
- 揭示「静态轨迹学习」与在线鲁棒性之间的鸿沟
- DOM 噪声与动态内容是主要失败源
- 与在线环境（WebArena）互补

## 对 openmate 借鉴
1. **网页工具返回要瘦身**：完整 DOM 不可直接喂模型，需可交互元素摘要
2. **动作可回放**：录制操作轨迹便于调试与回归
