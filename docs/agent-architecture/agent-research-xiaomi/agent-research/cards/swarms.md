# Swarms

## 一句话定位
kyegomez 的多 Agent 编排框架：用可组合 Swarm/Agent API 组织群体协作。

## 核心架构（3点）
1. **Agent 抽象**：系统提示 + 工具 + 循环控制
2. **多种 Swarm 拓扑**：顺序、并行、层级、委员会等编排原语
3. **生产化包装**：重试、结构化输出、日志等横切能力

## 稳定性亮点
- 拓扑多样，适合快速实验多 Agent 形态
- 社区活跃、迭代快
- ⚠️ 相对学术框架更偏「可运行库」，深度可恢复性需自行加固

## 对 openmate 借鉴
1. **先固化拓扑枚举**：顺序/分诊/委员会各自失败语义不同，别用一个 for 循环硬扛
2. **多 Agent 必须共享预算与取消信号**：避免子 Agent 泄漏与死循环
