# ToolBench

## 一句话定位
OpenBMB 大规模工具调用基准与数据：训练/评测 LLM 使用海量真实 API 的能力。

## 核心架构（4点）
1. **RapidAPI 工具池**：数千真实 API 组成工具集
2. **指令与轨迹数据**：生成可训练的调用轨迹
3. **评测协议**：衡量规划、选工具、多步调用成功率
4. **配套模型（ToolLLaMA 等）**：开源工具增强模型参考实现

## 稳定性亮点
- 把「工具调用」从 demo 推向可量化基准
- 暴露长工具列表下的选择与失败恢复问题
- API 变动是主要维护成本

## 对 openmate 借鉴
1. **工具描述质量决定上限**：像评测一样优化 tool schema 与错误信息
2. **长工具集要检索/分层**：不能把全部工具塞进每轮 prompt
