## 开发概述

实现7套UI主题配色系统（6标准+1自定义），适配OpenFace / Web面板 / Tauri桌面端 / 代码编辑器。所有主题遵循WCAG AA无障碍标准，低饱和、层次干净、语义色统一。

## 设计原则

1. 底色不纯黑不纯白，带微量色相偏移
2. 层级色同色系，明度±8~15
3. 主强调色1个，语义色≤4个
4. 语法高亮≤5色，大部分中性灰
5. 高亮色饱和度S 30~50
6. WCAG AA ≥4.5:1

## 自定义主题

- 9个核心色可调：主背景、正文、卡片、主强调、成功、警告、错误、次要文字、分割线
- 使用CSS `var(--custom-xxx, 默认值)` 模式
- 默认值 = Cream Mocha 色值
- 设置页面提供颜色选择器，实时预览
