**2. 智能体标准生命周期（固化）**

初始化 → 上下文加载 → 需求解析 → 任务规划 → 分步执行 → 工具调用/模型推理 → 结果聚合 → 反思复盘 → 任务完结/迭代重试

**2.1 阶段规范**

* **初始化阶段**：加载租户配置、角色设定、基础 Prompt、权限校验
* **上下文阶段**：读取短期记忆、会话历史、知识库片段
* **规划阶段**：拆解复杂需求为可执行子任务，生成执行链路
* **执行阶段**：串行/并行执行子任务，调用模型或工具
* **聚合阶段**：汇总子任务输出，统一整理最终结果
* **反思阶段**：校验结果合理性、识别缺陷、生成优化策略
* **完结阶段**：落库记忆、归档产物、推送事件、释放资源

**3. 核心能力规范**

**3.1 自动任务规划**

AgentCore 内置标准化拆解逻辑，支持复杂需求分层拆解、依赖排序、优先级调度、子任务并行/串行自适应，杜绝无序执行。

**3.2 标准化推理执行**

统一推理入参、上下文拼接、输出格式约束，统一拦截幻觉、无效输出、越权内容，保证输出可控、可解释。

**3.3 反思迭代机制**

每轮任务结束自动触发反思，校验：任务完整性、逻辑正确性、结果完备性、工具使用合理性，输出可追溯复盘报告，支持下一轮迭代优化。

**3.4 工具与插件调度**

统一插件调用时机、参数校验、结果解析、异常捕获，Agent 不直接依赖具体工具，完全通过插件体系解耦扩展。

**3.5 多 Agent 协同**

支持主从 Agent、对等 Agent 协同，任务委派、结果汇总、冲突校验、分工协作，遵循 A2A 协议标准通信。

**4. 状态与异常管控**

* 支持任务暂停、恢复、终止、重试、回滚标准化状态流转
* 模型超时、限流、熔断、工具异常、参数错误统一降级兜底
* 异常任务自动留存快照，支持事后复盘追溯

**5. 联动体系规范**

* 联动 PromptStore：拉取各阶段规划、执行、反思标准模板
* 联动 ModelGateway：统一模型调用、限流熔断、用量统计
* 联动 Memory：读写会话记忆、长期记忆、任务记忆
* 联动 EventBus：推送 agent 生命周期、任务变更、反思事件
* 联动 Telemetry：全阶段埋点观测、耗时统计、成功率统计

**6. 可观测与指标规范**
