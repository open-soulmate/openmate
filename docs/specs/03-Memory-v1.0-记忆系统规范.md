**OpenSoulMate\_AgentMemory\_v1.0\_智能体记忆管理规范（定稿冻结）**

**0. 总则**

**0.1 规范目的**

统一 OpenSoulMate 全集群 **智能体记忆存储、记忆分层、记忆写入、记忆召回、记忆遗忘、记忆合并、记忆过期、长期人格沉淀** 全流程标准。

解决 Agent 上下文丢失、对话割裂、记忆混乱、无效记忆堆积、无长期人格、跨会话无继承问题。
作为智能体 **长时自主心智底座**，实现「会话记忆→短期记忆→长期记忆→人格沉淀」完整闭环。

**0.2 适用范围**

* 所有 Agent 智能体实例记忆模块
* ACP 会话记忆写入流水线
* RAG 记忆召回融合模块
* 记忆压缩、摘要、合并、过期清理引擎
* 长期人格向量沉淀服务
* 跨会话、跨任务、跨节点记忆继承机制

**0.3 层级定位**

* **上层依赖**：ACP 人机会话、A2A 智能体协同
* **下层依赖**：Artifact 知识库、Vector 向量检索引擎
* **调度依赖**：TaskScheduler 异步记忆后台任务
* **可观测依赖**：Log&Trace 全链路日志规范

**0.4 基础强制约束**

* 记忆数据**全部持久化至 Artifact**，禁止内存裸存
* 所有记忆必须向量化，支持语义召回
* 严格三层记忆分层隔离，层级不可错乱
* 记忆读写必须带 traceId、sessionId、agentId 溯源
* 自动遗忘、自动压缩为系统强制机制，不可关闭

**1. 记忆三层分层架构（核心规范）**

**1.1 层级定义（强制固定）**

1. **会话记忆（Session Memory）**

* 生命周期：单次会话存续期间
* 存储形式：完整对话 raw 日志
* 作用：维持当前对话上下文连贯
* 销毁策略：会话销毁后进入异步归档

1. **短期记忆（Short-term Memory）**

* 生命周期：7 天
* 存储形式：结构化摘要 + 轻量向量
* 来源：会话结束后自动压缩生成
* 作用：近期任务、近期对话、近期偏好复用

1. **长期记忆（Long-term Memory）**

* 生命周期：永久保存
* 存储形式：高度凝练人格片段、事实沉淀、行为模式向量
* 来源：短期记忆筛选、高频事实、固定偏好、重复行为
* 作用：Agent 固定人格、认知积累、长期一致性

**1.2 层级流转规则**

会话记忆 → 自动压缩 → 短期记忆 → 筛选沉淀 → 长期记忆

**2. 核心数据模型**

**2.1 标准记忆条目模型**

|  |
| --- |
| json {  "memoryId": "mem-xxxx",  "agentId": "",  "sessionId": "",  "memoryLevel": "session|short|long",  "type": "fact|preference|skill|experience|persona",  "content": "",  "summary": "",  "embeddingRef": "",  "artifactId": "",  "weight": 0.7,  "accessCount": 1,  "lastAccessAt": 1788000000,  "expireAt": null,  "createdAt": 1788000000,  "updatedAt": 1788000000 } |

**2.2 记忆类型分类标准**

* fact：客观事实、知识、任务结果、文档信息
* preference：用户偏好、交互习惯、输出风格偏好
* skill：习得技能、执行流程、固定工作范式
* experience：历史执行经验、踩坑记录、解决方案
* persona：人格特征、语气、思维模式、角色定位

**3. 记忆写入流水线规范**

**3.1 实时写入**

* 每轮 ACP 对话结束自动写入**会话记忆**
* 携带完整上下文、用户输入、Agent 输出、时间戳

**3.2 会话后置压缩（异步任务）**

会话结束 30s 后自动触发：

1. 全文摘要生成
2. 关键信息提取
3. 去重、降噪、剔除无效闲聊
4. 生成短期记忆条目 + 向量索引

**3.3 长期记忆沉淀机制**

满足任意 2 条自动晋升长期记忆：

* 同一事实 / 偏好被访问 ≥3 次
* 连续多会话重复出现
* 高权重核心设定、人格设定
* 人工标记永久记忆

**4. 记忆召回规范**

**4.1 召回优先级**

长期记忆（人格核心） > 高频短期记忆 > 当前会话上下文

**4.2 召回策略**

* 语义相似度阈值：默认 0.75
* 最大召回条数：长期 5 条 + 短期 8 条
* 时间衰减：越新权重越高
* 访问增益：被读取过的记忆权重自动提升

**4.3 记忆融合规则**

召回记忆 → 去重冲突 → 权重排序 → 结构化注入 Prompt

**5. 记忆遗忘与清理规范**

**5.1 短期记忆过期**

* 7 天无访问自动过期归档
* 过期不删除，进入冷存储，不再主动召回

**5.2 无效记忆清理**

系统定时任务自动清理：

* 无意义重复闲聊
* 低价值重复片段
* 冲突过期旧记忆
* 空内容、残缺片段

**5.3 人工记忆管控**

支持：

* 手动标记永久记忆
* 手动删除单条记忆
* 手动合并相似记忆
* 手动重置人格记忆

**6. 标准 RPC 接口**

**6.1 memory/write 写入记忆**

**6.2 memory/recall 语义召回记忆**

**6.3 memory/compress 手动压缩会话记忆**

**6.4 memory/forget 主动遗忘指定记忆**

**6.5 memory/status 查询记忆统计**

**7. 权限与隔离规范**

1. Agent 记忆**严格私有隔离**
2. 禁止跨 Agent 主动读取他人长期记忆
3. 项目级共享记忆需显式授权共享策略
4. 记忆操作日志全部审计留存

**8. 依赖关联规范**

* 存储底座：Artifact 工件规范
* 语义底座：Vector 向量检索规范
* 异步任务：TaskScheduler 任务调度规范
* 链路追踪：Log&Trace 日志规范
* 权限控制：RBAC 权限规范
