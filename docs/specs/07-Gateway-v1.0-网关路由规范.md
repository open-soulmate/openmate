**OpenSoulMate\_Gateway\_v1.0\_网关路由规范（定稿冻结）**

**0. 总则**

**0.1 规范目的**

网关是系统**唯一统一流量入口**，屏蔽所有微服务后端细节，实现流量治理统一、安全策略统一、错误返回统一、链路追踪统一、访问审计统一，保障集群稳定、可控、可观测。

* 全局统一接入网关服务
* JSON‑RPC 协议转发层
* 全局鉴权拦截模块
* 限流、熔断、降级流量治理模块
* TraceId 生成与全链路透传模块
* 访问日志、操作审计日志归集模块
* 端口绑定、域名代理、TLS 终止层

**0.3 层级定位**

* **上游**：Web 前端、Tauri 客户端、第三方调用端
* **下游**：ACP、A2A、MCP、Artifact、Vector、TaskScheduler 所有微服务
* **职责边界**：网关只做「转发、治理、拦截、记录」，**禁止承载任何业务逻辑**
* **体系依赖**：RBAC 权限、全局错误码、全链路日志追踪规范

* 链路标识：网关统一生成 traceId，全链路强制透传
* 执行顺序：**先鉴权 → 先限流 → 再路由转发**
* 超时层级：网关超时 > 各服务接口超时，杜绝多层超时冲突

网关校验、限流、记录日志后**原样透传**至对应后端服务。

**3. 流量治理规范**

**3.1 限流策略**

支持四维限流：

* 全局总 QPS 限流
* 单项目维度限流
* 单 Token 用户限流
* 客户端 IP 限流

限流触发固定返回：**10007 RATE\_LIMIT**

**3.2 熔断降级策略**

1. 后端错误率超过阈值 → 自动熔断
2. 熔断期间直接返回服务不可用：**10008 SERVICE\_UNAVAILABLE**
3. 冷却时间结束自动半放探测，健康后恢复流量
4. 读接口可缓存降级，写接口禁止降级、直接拒绝

**3.3 超时控制**

* 通用接口全局超时：**60s**
* 批量异步任务超时：**300s**
* 超时统一返回：**10010 TIMEOUT**

**3.4 网关重试限制**

* **只读查询接口**：允许最多 1 次重试
* **写入 / 任务提交 / 变更类接口**：网关层禁止重试，防止脏数据、重复任务

**4. 安全与鉴权规范**

1. **所有外网入口路由默认强制鉴权**
2. 内部集群服务互通可绕过网关鉴权
3. Token 异常严格匹配全局错误码：

* 10004 Token 缺失
* 10005 Token 非法
* 10006 Token 过期

1. **所有写操作强制审计日志**：TraceId、IP、身份、时间、操作参数摘要

**5. 错误透传规范**

1. 后端服务返回的标准 error 结构 **原样透传**，网关不篡改错误码与描述
2. 网关自身产生的错误，严格遵守 ErrorCode\_v1.0 格式
3. 禁止裸文本报错，全网关统一结构化异常

**6. 日志与可观测规范**

网关强制记录每一条请求：

* traceId、请求 method、请求耗时、状态码、客户端 IP
* projectId、操作身份、是否写操作
* 限流 / 熔断 / 鉴权拦截标记

所有日志格式对齐 **Log&Trace 全局追踪规范**
