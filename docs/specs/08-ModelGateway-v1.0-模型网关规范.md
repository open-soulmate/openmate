# OpenSoulMate\_ModelGateway\_v1\.0\_模型网关规范（定稿冻结）

# 0\. 总则

## 0\.1 规范目的

定义 OpenSoulMate 集群**统一模型网关调度标准体系**，涵盖模型接入、路由分发、负载均衡、限流熔断、多模型适配、请求归一化、响应统一封装、故障降级、计费配额、链路隔离全套规范。

解决多模型适配混乱、调用口径不统一、负载不均、无分层限流、模型故障扩散、请求响应格式杂乱、无法统一观测管控等问题，构建**统一接入、智能调度、高可用、可限流、可观测、可降级**的集群 AI 模型统一代理底座。

## 0\.2 适用范围

- 全集群所有大模型、向量模型、本地小模型、第三方API模型的统一接入与调度

- 模型请求路由、负载分发、权重调度、实例健康探测模块

- 分层限流、租户配额、频率控制、并发限制、突发流量削峰模块

- 请求归一化、参数校验、格式适配、响应统一封装模块

- 模型故障探测、自动熔断、降级兜底、重试容错模块

- 模型调用监控、遥测采集、日志链路、用量统计、计费核算模块

- 与 EventBus、Plugin、Monitor、Telemetry 体系联动适配模块

## 0\.3 层级定位

- **上游**：Agent智能体、PromptStore、业务服务、租户应用、调度中心

- **下游**：各类LLM模型、向量模型、本地推理模型、第三方模型接口

- **体系依赖**：EventBus事件总线、Plugin插件系统、Telemetry遥测、Monitor监控、RBAC权限、Log\&Trace链路追踪、SLA服务等级规范

- **职责边界**：仅负责模型流量代理、调度、容错、管控、观测；**不参与模型推理计算、不执行业务逻辑决策**

## 0\.4 基础强制约束

1. 所有模型调用**必须经过ModelGateway统一代理**，禁止业务直连模型服务

2. 模型请求、响应数据结构全局统一固化，多模型差异由网关适配层兼容

3. 强制实现租户、服务、接口三层限流隔离，杜绝流量互相影响

4. 所有模型调用链路必须携带TraceId，全链路追踪、全量指标采集

5. 模型故障必须自动熔断降级，禁止单点模型故障扩散至全局集群

6. 模型上下线、流量变更、调用异常全部通过EventBus发布标准事件

7. 所有模型调用严格遵循RBAC权限、租户配额管控，无权限裸调用禁止通行

# 2\. 模型分类与接入规范

## 2\.1 四大模型接入类型（固化）

1. **LLM大语言模型**：通用对话、文本生成、推理问答，支持流式/非流式调用

2. **向量模型**：文本向量化、语义检索、相似度计算，适配知识库场景

3. **本地推理模型**：集群本地部署轻量化模型，低延迟离线推理

4. **第三方模型**：外部API模型，由网关完成鉴权、适配、容错、缓存兜底

## 2\.2 统一适配规范

- 所有模型差异化入参、出参由网关适配层统一抹平，上游业务无需感知模型差异

- 统一错误码映射、统一超时策略、统一重试机制、统一返回结构

- 流式响应统一分片、统一结束标识、统一异常中断规则

# 3\. 路由与负载均衡规范

## 3\.1 路由策略

- **精准路由**：按modelName精准匹配对应模型节点集群

- **权重路由**：支持多节点权重分发，实现流量灰度、容量分流

- **故障择优路由**：自动避开熔断、离线、高延迟节点，优先健康节点

- **租户隔离路由**：限定租户仅可调用授权模型，禁止越权调用

## 3\.2 负载均衡算法

默认采用**平滑加权轮询\+最小并发优先**混合策略，兼顾流量均匀性与实时负载最优，避免单节点压垮。

# 4\. 限流、配额与削峰规范

## 4\.1 四层限流隔离体系

- 集群全局限流：保障整体集群模型调用稳定性，防止打爆上游资源

- 租户Namespace限流：租户资源隔离，避免单租户抢占全局配额

- 服务级限流：单个业务服务流量管控，限制异常突发请求

- 模型级限流：单模型资源保护，防止单一模型过载宕机

## 4\.2 配额管控规则

- 支持按QPS、并发数、日Token总量三重配额限制

- 配额耗尽自动拦截，返回标准化超限错误码，触发告警

- 支持临时配额扩容、白名单豁免、时段配额差异化配置

# 5\. 容错、熔断与降级规范

## 5\.1 重试机制

- 网络异常、5xx服务异常自动重试，默认最大重试2次，间隔指数退避

- 业务参数错误、4xx异常禁止重试，避免无效流量堆积

## 5\.2 熔断机制

- 单模型节点1分钟错误率超20%，自动熔断5分钟，流量切换至备用节点

- 连续超时触发熔断，规避阻塞堆积

- 熔断状态实时上报监控、遥测，推送EventBus事件

## 5\.3 降级兜底策略

- 模型全部熔断/离线时，返回标准化兜底响应，保障业务不中断

- 支持本地缓存Prompt结果兜底、静态模板兜底、降级提示兜底

# 6\. 可观测与SLA规范

## 6\.1 核心监控指标（接入Monitor）

- 模型调用QPS、成功率、错误率、P50/P95/P99耗时

- Token消耗总量、租户用量排行、模型用量排行

- 限流次数、熔断次数、降级次数、重试次数

- 节点在线数、并发负载、健康分数

## 6\.2 SLA核算口径

模型网关可用性、延迟指标、错误率指标统一接入全局SLA体系，按Tier1服务标准核算考核。

# 7\. 插件联动与事件规范

- 前置插件：请求参数校验、Prompt脱敏、权限二次校验、配额预扣

- 后置插件：响应内容过滤、用量统计、日志归档、结果缓存

- 全量模型生命周期、调用异常、限流熔断事件推送EventBus，支持业务订阅扩展

# 8\. 权限与审计规范

- 模型调用、用量查询：租户只读权限

- 模型节点注册、配额配置、限流规则修改：运维权限

- 全局网关策略、熔断阈值、降级规则配置：管理员权限

- 所有模型变更、流量管控、配额调整、故障熔断操作永久审计留存
