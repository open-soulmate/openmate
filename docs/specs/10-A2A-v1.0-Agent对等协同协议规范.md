**OpenSoulMate A2A v1.0 Agent对等协同协议规范（定稿冻结）**

**0. 总则**

**0.1 规范目的**

定义 OpenSoulMate 体系 A2A（Agent to Agent Protocol）智能体对等协同协议，标准化 Agent 实例之间任务委派、子任务调度、工件同步、集群状态广播通信模型，实现多智能体分布式协同，统一跨进程、跨节点 Agent 通信标准。

**0.2 适用范围**

本规范适用于所有 OpenSoulMate 集群内 Agent 实例、A2A 网关、工件管理模块、任务调度模块。仅用于 Agent 之间业务协同，不用于人机交互、底层系统运维管控逻辑。

**0.3 三层协议边界严格界定**

* **ACP（人机层）**：人 ↔ Agent 会话、审批、前端交互
* **A2A（协同层）**：Agent ↔ Agent 任务委派、子任务调度、资源共享、集群协同
* **MCP（管控层）**：系统进程、配置、资源、运维底层管控

三层协议**链路隔离、报文隔离、权限隔离、错误码隔离**，禁止跨协议混用通道。

**0.4 协议基础约束**

* 底层标准：JSON-RPC 2.0 严格合规，扩展 SSE 流式事件
* 字符编码：统一 UTF-8
* 长连接主链路：ws://127.0.0.1:8092/ws/a2a
* HTTP 兜底短链：http://127.0.0.1:8092/rpc/a2a
* 通信模型：对等无主从、异步可溯源、支持分布式多节点

**2. 标准 A2A RPC 方法全集**

**2.1 a2a/task/delegate 任务委派（核心）**

**用途**：主 Agent 向子 Agent 下发可追溯子任务，支持父任务依赖、超时控制、上下文传递

请求：

|  |
| --- |
| json {  "jsonrpc":"2.0","id":1,  "method":"a2a/task/delegate",  "params":{  "task\_id":"task-xxxx",  "parent\_task\_id":"task-parent-xxxx",  "target\_agent":"hermes | opencode | openclaw | soulmate",  "task\_type":"execute | analyze | generate | validate",  "task\_context":{},  "timeout":30000,  "require\_result":true  } } |

响应：

|  |
| --- |
| json {  "jsonrpc":"2.0","id":1,  "result":{  "task\_id":"task-xxxx",  "status":"pending",  "accepted\_at":1788000000  } } |

**2.2 a2a/task/result 子任务结果回传**

**用途**：子 Agent 执行完成后回传结果、产物、日志、异常信息

请求：

|  |
| --- |
| json {  "jsonrpc":"2.0","id":2,  "method":"a2a/task/result",  "params":{  "task\_id":"task-xxxx",  "status":"success | failed | timeout",  "result\_data":{},  "artifact\_list":[],  "error\_msg":"",  "cost\_time":1200  } } |

**2.3 a2a/task/cancel 任务取消**

**用途**：父任务终止、手动终止子任务，释放资源

请求：

|  |
| --- |
| json {  "jsonrpc":"2.0","id":3,  "method":"a2a/task/cancel",  "params":{  "task\_id":"task-xxxx",  "cancel\_reason":"manual\_abort | parent\_task\_failed | timeout"  } } |

**2.4 a2a/artifact/sync 跨 Agent 工件同步**

**用途**：文档、代码、报表、结构化产物跨 Agent 共享

请求：

|  |
| --- |
| json {  "jsonrpc":"2.0","id":4,  "method":"a2a/artifact/sync",  "params":{  "artifact\_id":"art-xxxx",  "artifact\_type":"document | code | file | report | log",  "content":"",  "meta":{},  "target\_agent\_list":[]  } } |

**2.5 a2a/agent/heartbeat 节点心跳保活**

**用途**：集群在线感知、负载探测、异常节点剔除

请求：

|  |
| --- |

**3. A2A 标准事件清单**

* task.pending：任务进入待执行队列
* task.running：任务开始执行
* task.success：任务执行成功
* task.failed：任务执行异常
* task.canceled：任务被主动取消
* artifact.update：共享工件更新
* agent.offline：Agent 节点离线断连

**4. 通信强制规范**

1. 所有跨 Agent 业务协同**只允许走 A2A 链路**
2. 禁止通过 ACP 人机会话通道传递 Agent 任务数据
3. 所有子任务必须携带 parent\_task\_id 用于全链路溯源
4. 所有 A2A 通信必须携带 trace\_id 接入全局日志追踪
5. 任务、工件、节点状态变更必须全局广播
