# OpenSoulMate\_Plugin\_v1\.0\_插件扩展系统规范（定稿冻结）

# 0\. 总则

## 0\.1 规范目的

定义 OpenSoulMate 集群**统一插件扩展体系标准**，包含插件生命周期、挂载钩子、加载优先级、隔离机制、热更新规范、权限管控、依赖管理、异常熔断、事件联动全套规范。

解决集群功能扩展混乱、自定义逻辑侵入内核、插件加载冲突、热更新不稳定、无隔离导致主流程崩溃、扩展能力无统一收口等问题，构建**内核稳定、插件可扩展、热更新无损、安全隔离、可管控**的集群插拔式扩展底座。

## 0\.2 适用范围

- 全集群内核服务、Agent 智能体、模型网关、任务调度、记忆系统、知识库系统插件扩展

- 所有自定义业务插件、钩子插件、前置拦截插件、后置处理插件、定时扩展插件

- 插件打包、校验、加载、卸载、启用、禁用、热更新全流程模块

- 插件依赖解析、冲突检测、资源限流、异常熔断、隔离降级模块

- 插件日志、遥测、监控、审计、权限管控模块

- 插件与 EventBus、Telemetry、Monitor 体系联动模块

## 0\.3 层级定位

- **上游**：运维控制台、配置中心、插件市场、集群调度系统

- **下游**：全业务内核能力、钩子执行链路、事件总线、模型调用链路

- **体系依赖**：EventBus事件总线、Telemetry遥测、Monitor监控、RBAC权限、Log\&Trace链路追踪、ErrorCode错误码

- **职责边界**：仅负责插件生命周期管理、钩子调度、隔离管控、扩展能力挂载；**不改动内核源码、不接管核心主流程决策**

## 0\.4 基础强制约束

1. 所有扩展能力**必须通过插件实现**，禁止业务逻辑硬编码侵入集群内核

2. 插件目录结构、配置文件、钩子命名、入参出参格式全局统一固化

3. 插件必须支持**热加载、热卸载、热更新**，更新过程不中断集群主业务

4. 插件运行强制资源隔离，CPU、内存、执行时长限流，异常自动熔断隔离

5. 所有插件执行链路必须携带 TraceId，全链路可追踪、可监控、可审计

6. 插件启停、更新、执行、报错全部通过 EventBus 发布标准事件，接入遥测监控体系

7. 插件无最高权限，所有操作严格遵循 RBAC 权限管控体系

# 2\. 插件分类与钩子规范

## 2\.1 四大插件类型（固化分类）

1. **前置拦截插件**：业务执行前校验、过滤、参数修正、权限二次校验

2. **后置处理插件**：业务执行后数据加工、结果格式化、日志归档、数据同步

3. **事件监听插件**：订阅 EventBus 标准事件，实现异步扩展逻辑

4. **定时任务插件**：自定义周期巡检、数据清理、状态同步、报表统计

## 2\.2 全局标准钩子点位（固定不可新增）

### 2\.2\.1 Agent 核心钩子

- `agent.task.before` 任务执行前置钩子

- `agent.task.after` 任务执行后置钩子

- `agent.task.error` 任务异常钩子

- `agent.memory.process` 记忆处理钩子

### 2\.2\.2 模型网关钩子

- `model.request.before` 模型请求前置拦截

- `model.response.after` 模型返回后置加工

- `model.rate.limit` 限流拦截钩子

### 2\.2\.3 系统通用钩子

- `system.config.change` 配置变更钩子

- `system.event.receive` 事件接收钩子

- `system.health.check` 健康检查扩展钩子

# 3\. 加载优先级与执行顺序

## 3\.1 优先级区间规范

- **0\-20**：系统核心防护插件（限流、熔断、安全校验）最高优先执行

- **21\-50**：通用业务预处理插件

- **51\-80**：自定义扩展业务插件

- **81\-100**：后置日志、统计、归档类插件（最后执行）

同优先级插件按插件ID字典序串行执行，支持并行配置声明。

# 4\. 热更新与生命周期规范

## 4\.1 完整生命周期

校验入库 → 依赖解析 → 资源预加载 → 注册钩子 → 启用运行 → 热更新覆盖 → 禁用冻结 → 卸载回收

## 4\.2 热更新强制规则

- 热更新采用**双实例平滑切换**，先加载新版本、校验通过后再销毁旧版本

- 更新过程无业务中断、无请求丢失、无状态错乱

- 版本迭代必须兼容历史入参，禁止破坏性变更

- 更新失败自动回滚，保留旧版本正常运行，触发告警

# 5\. 资源隔离与熔断降级规范

## 5\.1 资源限流规则

所有插件强制配置资源上限，超出限制立即终止执行，标记异常，不影响内核服务。

## 5\.2 异常熔断机制

- 单插件1分钟内异常次数超10次，自动熔断5分钟

- 超时、死循环、资源溢出直接强制终止进程上下文

- 熔断状态实时上报 Monitor、Telemetry，生成监控指标与告警

# 6\. 权限与审计规范

- 插件列表查看、执行日志查询：只读权限

- 插件上传、启用、禁用、热更新：运维权限

- 插件资源阈值修改、全局钩子配置：管理员权限

- 所有插件变更、执行、熔断、回滚操作永久审计，绑定 TraceId、操作人、时间戳

# 7\. 体系联动规范

- 事件联动：插件全生命周期事件统一推送 EventBus

- 遥测联动：插件耗时、异常、资源占用全量接入 Telemetry

- 监控联动：自动生成插件QPS、错误率、耗时、熔断次数监控指标

- 链路联动：所有插件执行链路继承主链路 TraceId，完整串联追踪
