••••2.四层命名空间隔离与优先级规范

2.1命名空间层级定义

1. cluster集群级：全局公共基础配置，所有节点默认继承，优先级最低

2. project项⽬级：独⽴项⽬专属配置，覆盖集群全局配置

3. service服务级：指定微服务全实例配置，覆盖项⽬级配置

4. instance实例级：单节点专属个性化配置，优先级最⾼

2.2最终⽣效优先级（从⾼⾄低）

instance > service > project > cluster 

3.配置类型与前置校验规范

3.1⽀持数据类型

string ：通⽤⽂本配置

number ：整数/浮点数，⽀持值域校验

boolean ：布尔开关配置

json ：结构化复杂配置，提交强制语法校验

3.2保存前置强制校验

1. 格式合法性校验（JSON、数值、布尔严格校验）

2. ⾃定义值域校验（min、max、枚举⽩名单）

3. 操作权限校验（匹配命名空间修改权限）

4. 敏感配置加密校验，禁⽌明⽂⼊库

4.客⼾端接⼊与热更新规范

4.1服务启动加载流程

1. 服务启动主动拉取对应层级完整配置集

2. 加密落盘本地缓存⽂件

3. 建⽴⻓连接订阅配置变更事件

4. 启动30s定时轮询兜底，防⽌⻓连接断连丢失变更

4.2热更新机制

needRestart=false ：配置变更实时热加载，业务⽆感⽣效，⽆需重启服务

•••••needRestart=true ：底层核⼼配置（端⼝、数据库地址、密钥），变更仅记录，不热更新，
提⽰重启实例⽣效

4.3变更事件链路

配置变更推送→客⼾端拉取新版本→合法性校验→更新内存与本地缓存→触发业务回调→⽇志留

存变更记录

5.灰度发布与版本回滚规范

5.1灰度策略

⽀持按「实例ID、项⽬ID、服务集群」多维度灰度分批推送，避免全量变更雪崩。

5.2灰度管控

默认灰度观察期5分钟

观察期内可⼀键暂停、终⽌灰度

异常⾃动触发灰度回滚保护

5.3版本回滚规则

所有历史版本永久保存，不可删除、不可覆盖

回滚操作⽣成全新版本记录，全程可追溯

⽀持单条配置、批量配置⼀键回滚

6.敏感配置安全规范

1. 敏感配置标记 isEncrypted=true ，数据库全程密⽂存储

2. 服务间传输全程TLS加密，禁⽌明⽂传输

3. 客⼾端本地缓存仅存密⽂，运⾏内存动态解密使⽤，禁⽌明⽂落盘

4. 敏感配置变更、查看、下载操作触发⾼权限校验与独⽴告警

7.标准RPC接⼝规范
