**1. 核心概念定义**

**1.1 主体身份体系**

1. **User 用户主体**
   真实使用方，唯一 user\_id，归属所有会话、资源、权限。
2. **Session 会话主体**
   单次交互身份载体，**所有权限校验的最小执行单元**。
3. **Agent 服务主体**
   各智能体服务身份，用于 A2A 跨节点授权、服务间鉴权。
4. **MCP 管控主体**
   系统超级管控身份，拥有全局运维、配置、权限管理能力。

**1.2 权限核心原则**

1. **最小权限原则**
   默认禁止，仅显式授权可执行。
2. **会话隔离原则**
   权限、资源、文件、状态严格绑定 session\_id。
3. **可审计原则**
   所有权限校验、授权、拒绝、变更必须落日志与审计 Artifact。
4. **逐级降级原则**
   超权限操作直接拦截，不预警、不放行、不静默失败。

**2. 全局五层 RBAC 模型（强制标准）**

模型：**User → Role → Permission → Resource → Action**

**2.1 层级说明**

1. **User 用户**：身份持有者
2. **Role 角色**：权限集合模板（管理员 / 普通用户 / 访客 / 运维）
3. **Permission 权限项**：最小授权单元（单个工具、接口、操作）
4. **Resource 资源**：会话、文件、工件、配置、任务
5. **Action 操作**：读 / 写 / 执行 / 删除 / 审批 / 修改配置

**2.2 授权逻辑**

* 一个用户可绑定**多个角色**
* 一个角色包含**多个权限项**
* 权限最终控制**资源 + 操作**
* 会话继承创建者用户的权限快照

**3. 身份认证规范**

**3.1 认证方式**

1. **Session Token 会话认证（默认）**
   ACP 会话创建下发短时令牌，绑定 session\_id，用于前端交互鉴权。
2. **Service Token 服务认证**
   Agent、网关、MCP 内部通信长期服务令牌，用于 A2A/MCP 内部调用。
3. **Admin Key 超级认证**
   本地运维、本地初始化、紧急恢复使用。

**3.2 认证流程**

1. 请求携带 Token
2. 网关统一校验有效性、过期、黑名单
3. 解析获得 user\_id、session\_id、agent\_id、角色列表
4. 注入上下文，后续所有鉴权直接取用
5. 认证失败返回 -32001 鉴权失败

**3.3 Token 安全规则**

1. 禁止明文传输，全程 HTTPS / 内网加密
2. 会话 Token 随会话销毁自动失效
3. 支持手动吊销、批量吊销
4. 泄露检测：异地、异常频次自动风控冻结

**4. 权限分类体系（全局唯一）**

**4.1 会话权限 SessionPerm**

* 创建会话、恢复会话、关闭会话
* 查看自身会话状态、日志、产物
* 控制会话内任务启停

**4.2 工具权限 ToolPerm**

粒度到**单个 Skill/Tool**：

* tool:read 读取工具信息
* tool:exec 执行工具
* tool:write 工具写文件
* tool:delete 工具删除文件
* tool:network 工具网络请求

**4.3 工件权限 ArtifactPerm**

* art:view 查看产物
* art:download 下载
* art:edit 修改
* art:delete 删除
* art:share 跨会话共享

**4.4 任务权限 TaskPerm（A2A）**

* task:create 新建子任务
* task:delegate 委派 Agent
* task:cancel 终止任务
* task:view 查看任务日志

**4.5 系统管控权限 MCPPerm**

* sys:config 配置读写
* sys:log 日志查看导出
* sys:storage 存储清理配额
* sys:agent 进程启停管理
* sys:auth 权限分配、角色修改

**4.6 高危权限（单独审批流）**

以下操作必须**人工审批或特权白名单**：

* 文件删除、批量删除
* 命令行执行
* 外网提交、数据外传
* 配置覆写、系统参数修改
* 跨用户资源访问

**5. 会话级权限隔离规则（红线强制）**

1. 所有工具执行、文件读写、产物生成 **归属当前 session**
2. 禁止任何跨 session 读取、写入、修改、删除资源
3. A2A 子任务权限不能超越主会话权限
4. 子 Agent 仅拥有主会话下放的**最小子集权限**
5. 会话冻结 / 销毁后，该会话权限立刻失效

**6. A2A 跨 Agent 权限规范**

1. 主 Agent 拥有完整会话权限
2. 子 Agent 默认**零权限**
3. 主任务委派时按需授予临时工具权限、工件只读权限
4. 子任务结束立即回收临时权限
5. 禁止子 Agent 主动申请越级权限

**7. 角色预设规范（系统内置不可删除）**

**7.1 admin 超级管理员**

拥有全部权限，可配置、可运维、可授权、可审计

**7.2 user 标准用户**

拥有正常对话、工具执行、自有资源管理，无系统配置权限

**7.3 guest 访客**

仅对话只读，禁止文件写入、禁止网络、禁止持久化留存

**7.4 ops 运维账号**

仅日志、监控、进程查看，无业务操作与配置修改权限

**8. 权限校验执行流程（统一全局链路）**

1. 网关认证身份
2. 加载用户角色与权限列表
3. 匹配当前操作所需权限项
4. 校验资源归属（session/owner 匹配）
5. 高危操作校验审批状态
6. 通过放行，拒绝返回标准错误码 + 审计日志

**8.1 权限拒绝标准返回**

* 错误码：-32011 工具权限不足
* 强制记录：拒绝时间、主体、操作、资源、IP、TraceID

**9. 权限审计规范**

所有鉴权行为强制留存：

1. 权限通过记录
2. 权限拒绝记录
3. 角色变更记录
4. 权限授权 / 回收记录
5. 高危操作审批记录

所有审计数据生成**不可篡改 Artifact 归档**，永久留存。

**10. MCP 权限管控能力**

1. 在线角色配置、权限项开关
2. 用户权限快照查看
3. 异常越权行为统计告警
4. 高危操作大盘
5. 批量权限回收、会话冻结

**11. 红线禁止规则**

1. ❌ 禁止默认全开放权限
2. ❌ 禁止跨会话资源越权访问
3. ❌ 禁止子 Agent 超权限执行
4. ❌ 禁止绕过鉴权直接调用工具 / 接口
5. ❌ 禁止高危操作无审计、无留痕
6. ❌ 禁止业务代码硬编码跳过权限校验

**12. 兼容迁移规范**

* 旧版无鉴权裸调用逻辑全部废弃
* 所有工具、接口、任务强制接入 RBAC 校验
* 网关层统一拦截，无权限直接拦截
