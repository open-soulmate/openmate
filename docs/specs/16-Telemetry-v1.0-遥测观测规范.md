# OpenSoulMate\_Telemetry\_v1\.0\_遥测观测规范（定稿冻结）

# 0\. 总则

## 0\.1 规范目的

定义 OpenSoulMate 集群**统一可观测遥测体系标准**，规范日志\(Log\)、链路追踪\(Trace\)、指标\(Metric\)、事件\(Event\)四类遥测数据的采集、格式化、上报、聚合、存储、关联、采样、脱敏全套机制。

解决集群观测数据碎片化、格式不统一、链路断裂、指标无法关联、日志无结构化、采样策略混乱、排查链路割裂、无法全局溯源等问题，构建**全量采集、全域关联、统一口径、低侵入、高性能、可审计**的集群一体化遥测观测底座。

## 0\.2 适用范围

- 全集群微服务、Agent智能体、模型网关、插件系统、事件总线、调度中心所有组件

- 遥测数据埋点、自动采集、手动上报、批量聚合、异步上报模块

- Trace链路生成、上下文传递、跨服务串联、链路合并模块

- 结构化日志格式化、分级、脱敏、切片、归档模块

- 业务指标、系统指标、自定义指标统一采集与上报模块

- 遥测采样策略、流量裁剪、性能限流、数据去重模块

- 与 Monitor、EventBus、Plugin、SLA、Log\&Trace 体系联动适配模块

## 0\.3 层级定位

- **上游**：全集群业务组件、插件系统、事件总线、模型网关、调度服务

- **下游**：监控存储、日志存储、链路追踪引擎、告警中心、SLA核算引擎

- **体系依赖**：Monitor监控、EventBus事件总线、Plugin插件系统、SLA服务等级、RBAC权限、Log\&Trace链路追踪

- **职责边界**：仅负责全域观测数据采集、标准化、关联上报；**不执行业务逻辑、不参与故障决策、不管控集群资源**

## 0\.4 基础强制约束

1. 全集群所有服务**强制统一遥测埋点规范**，日志、Trace、指标格式全局固化，禁止私有格式

2. 所有请求链路必须生成唯一 TraceId，跨服务、跨组件、跨插件全程透传，禁止链路断裂

3. 核心链路全量采集，非核心链路分级采样，兼顾可观测性与集群性能

4. 所有遥测数据强制携带集群、租户、服务、实例、时间戳维度，支持多维聚合统计

5. 敏感数据强制脱敏，禁止明文泄露密钥、账号、用户隐私、模型密钥信息

6. 遥测采集低侵入设计，禁止阻塞主业务流程，异常自动降级不影响核心服务运行

7. 所有系统事件、插件执行、模型调用、任务生命周期统一通过遥测体系归档记录

# 2\. 四大遥测数据规范

## 2\.1 链路追踪 Trace 规范

- **链路生成规则**：入口请求生成全局 TraceId，下游所有组件自动透传，不允许断链、改链、丢链

- **Span 拆分规则**：服务调用、插件执行、模型请求、事件消费、任务执行单独生成子Span

- **状态判定**：业务异常、系统报错、超时、取消统一标记失败状态，用于故障统计

- **链路关联**：日志、指标、事件全部绑定同一TraceId，实现一键全链路检索

## 2\.2 结构化日志 Log 规范

- 禁止纯文本无格式日志，所有日志强制结构化、带维度、带链路ID

- 日志分级严格固化：Debug调试、Info正常、Warn预警、Error故障

- Error级别日志必须携带堆栈信息，用于问题定位

- 自动脱敏密钥、Token、隐私字段、模型鉴权信息

## 2\.3 监控指标 Metric 规范

- 统一四类指标类型：计数器、仪表盘、直方图、汇总值

- 所有指标命名统一 `模块_能力_指标` 小写下划线格式

- 强制携带租户、服务、模型、状态通用标签，支持多维筛选聚合

- 自动对接 Monitor 监控中心，生成大盘、告警、SLA统计数据

## 2\.4 事件 Event 遥测规范

- 订阅 EventBus 全量标准事件，完成事件统一归档观测

- 系统变更、插件启停、模型熔断、配置更新全部纳入遥测记录

- 事件数据与链路、指标、日志数据互相关联，构建完整观测视图

# 3\. 采样与性能优化规范

## 3\.1 分级采样策略（固化）

- **核心链路（100%全采）**：模型调用、Agent任务、核心接口、故障异常链路

- **普通链路（50%采样）**：常规心跳、状态上报、轻量查询

- **低优链路（10%采样）**：日志打印、缓存查询、定时巡检空轮询

## 3\.2 性能防护机制

- 遥测上报全部异步队列处理，绝不阻塞主业务

- 队列堆积自动限流、丢弃低优数据，保护集群性能

- 采集异常自动降级，关闭非核心采集，优先保障业务可用

# 4\. 全域关联观测规范

- **一ID全查**：通过TraceId可一次性查询对应链路、日志、指标、事件、插件记录、模型调用记录

- **故障自动聚合**：同一链路所有异常数据自动汇总，用于故障复盘与SLA追责

- **租户隔离观测**：所有遥测数据支持按Namespace隔离查询，租户仅可见自身数据

# 5\. 插件与事件联动规范

- 插件执行全流程埋点：加载、运行、异常、熔断、耗时全部遥测归档

- EventBus所有事件发布、消费、失败、重试全量采集

- 支持自定义插件遥测钩子，允许业务扩展自定义观测指标

# 6\. SLA 与监控联动规范

- 遥测原始数据为 SLA 可用性、错误率、耗时指标的唯一数据源

- 所有故障时长、异常次数、性能劣化数据由遥测聚合生成

- 自动输出SLA复盘原始观测数据，保证核算可追溯、可审计

# 7\. 权限与审计规范

- 租户遥测数据查询：租户只读权限，仅可查看自身Namespace数据

- 全集群观测数据查询、采样配置查看：运维权限

- 遥测采集规则、采样比例、脱敏策略修改：管理员权限

- 所有观测配置变更、数据导出操作永久审计留存
