**2. 指标类型与全局命名规范**

**2.1 四类基础指标（固定不可新增）**

1. **Gauge 瞬时指标**
   适用于实时状态值：CPU、内存、磁盘、队列积压、在线连接数、温度、负载
2. **Counter 累加计数器**
   只增不减，适用于统计总量：请求总数、成功数、失败数、任务总数
3. **Histogram 直方图指标**
   适用于耗时分布统计：接口 RT、任务执行耗时、检索延迟
4. **Summary 分位数摘要指标**
   预计算 P50/P90/P95/P99 延迟，用于 SLA 精准核算

**2.2 全局统一命名规则**

格式固化：指标类型\_业务域\_指标含义

标准前缀：

* gauge\_ 瞬时状态指标
* counter\_ 累计计数指标
* histogram\_ 耗时分布指标
* summary\_ 分位数统计指标

标准示例：

* counter\_rpc\_request\_total RPC 总请求数
* gauge\_service\_cpu\_usage 服务 CPU 使用率
* histogram\_rpc\_duration\_seconds RPC 耗时分布
* gauge\_task\_queue\_pending 任务队列积压数

**2.3 强制固定维度标签（不可缺失、不可删除）**

* clusterId 集群 ID
* serviceName 服务名称
* instanceId 实例唯一 ID
* nodeId 物理节点 ID
* namespace 项目隔离空间

业务可**增量追加**自定义标签，禁止删减基础标签。

**3. 统一采集策略**

**3.1 标准化采集频率（可配置中心覆盖）**

* 节点系统资源指标：15s / 次
* 服务 CPU / 内存 / 连接指标：10s / 次
* RPC 吞吐、错误率、延迟指标：10s / 次
* 任务队列、业务状态指标：15s / 次
* 深度业务统计、慢查询指标：30s / 次

**3.2 双采集模式互为兜底**

1. **Pull 主动拉取（默认）**
   监控中心定时拉取各服务 /metrics 标准端点
2. **Push 主动推送（补充）**
   短生命周期任务、临时作业主动推送指标至指标网关

**4. 指标存储分层与生命周期**

**4.1 四级存储精度体系**

1. **原始高精度数据**：保留 7 天，用于精细故障复盘、秒级排查
2. **5 分钟聚合数据**：保留 30 天，用于日常运维观测、性能分析
3. **1 小时聚合数据**：保留 180 天，用于容量趋势、月度复盘
4. **月度归档聚合数据**：长期冷存储，用于年度 SLA 审计、容量规划

**4.2 自动生命周期机制**

* 高精度数据自动降精度、自动聚合
* 过期原始数据自动清理，保留聚合统计结果
* 杜绝存储无限膨胀，兼顾排查精度与存储成本

**5. 四层监控大盘规范**

**5.1 集群总览大盘**

全局节点在线数、整体 CPU / 内存水位、集群总 QPS、全局错误率、异常实例统计、告警总览

**5.2 服务维度大盘**

单服务多实例横向对比、QPS 趋势、错误率趋势、P95 延迟、资源负载分布

**5.3 实例维度大盘**

单实例精细监控：线程数、连接数、队列积压、IO 负载、单次请求延迟波动

**5.4 业务专项大盘**

向量检索、知识库解析、Agent 任务调度、A2A 协同、记忆压缩专项指标看板

**5.5 大盘权限隔离**

* 管理员：查看全集群所有大盘
* 运维：查看基础设施 + 全服务监控
* 项目用户：仅查看所属 Namespace 业务指标

**6. 告警分级与治理规范**

**6.1 三级告警等级**

1. **WARN 预警**
   资源缓慢上涨、轻微抖动、非核心指标异常，不影响核心业务
2. **ERROR 错误**
   接口错误率上升、延迟超标、队列堆积，影响部分业务体验
3. **CRITICAL 紧急故障**
   节点失联、服务大面积异常、存储满载、核心链路中断，集群风险

**6.2 告警防风暴机制**

* 强制持续时间判定（默认 2min），过滤瞬时尖刺
* 支持按节点 / 服务维度告警抑制，父故障抑制子告警
* 支持自定义静默时段、临时屏蔽告警
* 告警分组推送，同类故障聚合合并

**7. 强制基础埋点指标清单**

所有微服务必须完整实现以下埋点，缺失视为不规范实例：

1. **系统资源指标**
   CPU 使用率、内存使用率、磁盘使用率、磁盘 IO、网络吞吐
2. **RPC 核心指标**
   请求总数、成功数、失败数、拒绝数、P50/P90/P95/P99 耗时
3. **任务队列指标**
   待处理数、消费速率、失败重试数、队列阻塞时长
4. **依赖健康指标**
   下游服务调用成功率、平均延迟、异常次数
5. **进程基础指标**
   线程 / 协程数、文件句柄数、内存 GC 波动、进程运行时长

**8. 标准接口规范**

* GET /metrics 标准化指标暴露端点
* monitor/metric/push 指标主动推送接口
* monitor/query 指标条件查询、趋势查询
* monitor/dashboard/list 获取大盘配置与视图
* monitor/rule/list 查询所有告警规则
* monitor/silence/create 创建临时告警静默

**9. 权限与审计规范**

1. 指标查看、大盘浏览：基础只读权限
2. 自定义指标埋点、大盘编辑：运维权限
3. 告警规则修改、静默、关闭：管理员权限
4. 所有规则变更、大盘修改、告警操作**永久审计留存**，绑定 TraceId、操作人
