解决集群各服务可用性口径混乱、指标不统一、无量化服务承诺、故障影响无法精准核算、SLA 报告无自动化标准、运维考核无依据等问题，构建**可量化、可审计、可追溯、可考核**的集群服务等级保障体系，支撑对外业务承诺、内部运维考核、故障复盘、长期容量规划。

**0.2 适用范围**

* 全集群微服务、网关、调度中心、向量检索、Artifact 知识库、AgentMemory、TaskScheduler

**0.3 层级定位**

* **上游**：运维控制台、监控中心、告警中心、报表系统

* **体系依赖**：Monitor 指标监控、Health 健康检查、RBAC 权限、全局错误码、链路追踪
* **职责边界**：仅负责 SLA 统计、核算、定级、报表、复盘管理，**不干预业务流量、不执行自动扩缩容与故障自愈**

**0.4 基础强制约束**

1. 全局 SLA 指标、计算公式、统计口径**完全统一固化**，所有服务强制对齐，禁止私有口径
2. SLA 原始数据强制来源于 Monitor 监控时序指标，杜绝人工篡改原始数据
3. 严格区分计划维护与非计划故障，仅非计划故障参与 SLA 扣减
4. 统计维度三层固化：集群级、服务级、租户 Namespace 级
5. 主核算周期为自然月，支持周度、季度汇总复盘
6. 所有故障登记、SLA 修正、基线变更、复盘操作**全量审计、带 TraceId、永久留存**

**2. 核心 SLA 指标与统一计算公式**

**2.1 服务可用性（核心基线指标）**

**可用性 = 周期内正常可用时长 / 统计周期总时长**

可用判定标准：

* 服务 Readiness 就绪、Liveness 存活
* 接口无大面积 5xx 系统异常
* 无集群级熔断、隔离、停机事件

不计入不可用：

* 4xx 业务参数错误、权限拒绝、租户非法请求
* 租户侧网络、客户端故障
* 已备案计划维护窗口

**2.2 P95 接口响应延迟**

取自 Monitor histogram 标准分位数指标，统计周期内 RPC 接口 P95 耗时，作为性能 SLA 基线。

**2.3 服务错误率**

**错误率 = 5xx 系统错误请求数 / 全部有效业务请求总数**
仅统计服务端系统故障，业务合法异常不纳入考核。

**2.4 异步任务成功率**

**任务成功率 = 成功完结任务数 / 全部有效提交任务数**
专项用于 Agent 调度、后台 Worker、异步解析任务 SLA 考核。

**4. 故障四级分级规范（P1~P4）**

* **P1 重大故障**：核心服务全域中断、多租户业务瘫痪，最高优先级全员响应
* **P2 严重故障**：单租户 / 单核心链路完全不可用，业务中断，紧急故障处理
* **P3 一般故障**：服务可用但性能降级、部分功能异常、队列堆积，影响体验
* **P4 轻微故障**：非核心模块告警、无业务影响，常规工单迭代修复

**5. SLA 精准核算规范**

**5.1 维护窗口豁免机制**

所有预先审批、公告、定时的低峰维护，自动从统计时长中剔除，不参与 SLA 扣减；突发紧急维护归类为非计划故障，正常扣减。

**5.2 故障影响加权算法**

多实例集群不按「实例在线数粗算」，采用**流量加权不可用时长**，精准反映真实业务影响。

**5.3 人工修正约束**

月度报表冻结后仅允许管理员审批修正，所有修正记录永久审计，不可删除篡改。

**5.4 免责排除项**

租户自身错误、客户端网络异常、外部第三方依赖故障，提供证据后可免责剔除。

**6. SLA 看板与自动化报表体系**

**6.1 三级可视化看板**

1. **集群总览 SLA 大盘**：全局 Tier0/Tier1 达成率、故障统计、月度趋势
2. **服务维度 SLA 大盘**：单服务 12 个月可用性、延迟、错误率连续趋势
3. **租户维度 SLA 大盘**：项目级可用率、故障清单、服务质量汇总

**6.2 标准化月度报告内容**

包含：基线承诺、实际达成、不可用时长、故障清单、根因归类、问题统计、整改待办、容量预测，支持 PDF 固化导出。

**7. 权限与审计规范**

* SLA 数据查看、报表浏览：项目只读权限
* 故障登记、事件定级：运维权限
* 基线配置、数据修正、报表冻结：管理员权限 + 审批流
* 所有变更、修正、定级、复盘操作 **TraceId 全链路永久审计**

**8. SLA 复盘闭环规范**

每月自动触发 SLA 复盘：

* 未达标服务强制输出 RCA 根因分析
* 输出整改方案、责任人、截止时间
* 纳入工单持续跟踪闭环
* 连续两月不达标服务强制架构评审、容量扩容、架构优化
