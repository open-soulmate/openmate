**OpenSoulMate\_Health\_v1.0\_集群健康检查规范（定稿冻结）**

**0. 总则**

**0.1 规范目的**

定义 OpenSoulMate 分布式集群**统一健康探测、状态分级、故障判定、流量隔离、自动自愈、事件告警**完整标准。

解决各服务健康口径不统一、只探存活不探业务、故障发现滞后、抖动误判、异常实例无法自动下线、无自愈闭环等问题。作为集群稳定性核心底座，保障集群高可用、可观测、可自愈。

**0.2 适用范围**

* 全局集群健康检查中心服务
* 全集群所有微服务实例
* Worker 工作节点进程探针
* 故障判定与流量隔离模块
* 自动自愈调度执行模块
* 健康指标采集、状态看板、故障告警、审计追溯模块

**0.3 层级定位**

* **上游**：运维控制台、集群编排、监控告警系统
* **下游**：全部业务服务、后台任务、异步 Worker
* **体系依赖**：配置中心、任务调度、链路追踪、RBAC、全局错误码
* **职责边界**：仅负责探测、判定、采集、隔离、自愈、告警，**不承载任何业务逻辑**

**0.4 基础强制约束**

* 全局固定三类探针：存活探针、就绪探针、业务健康探针
* 所有服务强制暴露标准化健康接口，路径统一固化
* 故障判定必须「连续多次失败」生效，杜绝瞬时网络抖动误判
* 实例异常优先**优雅下线、摘除流量**，禁止粗暴销毁业务进程
* 所有健康变更、自愈动作、故障事件必须落日志、带 TraceId、可审计追溯
* 健康阈值、探测周期、自愈策略全部由配置中心统一管控，禁止代码硬编码

**2. 三类探针强制规范**

**2.1 Liveness 存活探针**

* **接口路径**：/health/live
* **作用**：检测进程是否卡死、崩溃、失联
* **探测超时**：3s
* **异常判定**：进程无响应、卡死、panic
* **默认自愈**：触发安全重启

**2.2 Readiness 就绪探针**

* **接口路径**：/health/ready
* **作用**：判断实例是否**可接收新流量**
* **场景**：启动初始化、依赖未就绪、配置加载中
* **探测超时**：3s
* **异常动作**：网关自动摘除流量，不转发新请求，存量任务正常跑完

**2.3 BusinessHealth 业务健康探针**

* **接口路径**：/health/business
* **作用**：真实业务可用性检测，代表服务实际服务能力
* **探测超时**：5s
* **三级状态**
* normal：完全健康，业务正常
* degraded：降级，部分功能可用、资源偏高、延迟上涨
* fault：完全故障，依赖断连、大面积报错、队列堆积溢出
* **检测维度**：CPU / 内存 / 磁盘、RPC 错误率、P95 耗时、下游依赖连通性、任务积压

**3. 探测策略与判定规则**

**3.1 探测周期（可配置）**

* 存活探针：10s / 次
* 就绪探针：10s / 次
* 业务探针：15s / 次

**3.2 抖动防护（强制）**

* 异常生效：**连续 3 次探测失败** 标记故障
* 恢复生效：**连续 2 次探测成功** 标记恢复
* 彻底杜绝瞬时网络抖动、瞬时负载峰值导致误判

**3.3 探测模式**

* 主动 Pull：健康中心轮询所有实例
* 被动 Push：实例主动上报状态变更
* 双模式互为兜底，保证状态实时一致

**4. 实例状态流转 & 流量治理**

1. **启动初始化**：readiness = notReady → 不接入流量
2. **启动完成**：readiness = ready → 网关正常分发流量
3. **业务降级 degraded**：保留流量、自动限流、上报告警、持续观测
4. **业务故障 / 存活异常**：立刻摘除流量、隔离实例、触发自愈
5. **实例下线**：先置 notReady → 等待 30s 任务窗口期 → 优雅退出

**5. 自动自愈分级规范**

所有自愈策略可在配置中心开关、可白名单禁用、可人工审批。

**5.1 自愈动作枚举**

* none：仅告警，人工处理（数据存储类服务默认）
* isolate：流量隔离，保留进程，用于故障排查
* restart：安全重启实例，解决内存泄漏、卡死、临时异常
* evacuate：节点疏散，本节点全部实例下线，任务迁移至健康节点

**5.2 安全约束**

* **存储类服务（向量库、Artifact）禁止自动重启**，仅隔离 + 告警
* 计算类、无状态服务允许自动重启自愈

**6. 健康指标采集规范**

业务探针必须实时返回快照指标：

* 系统资源：CPU、内存、磁盘使用率
* 业务指标：RPC 错误率、P95 响应耗时、请求 QPS
* 任务状态：队列积压、运行中任务数、失败率
* 依赖状态：数据库、向量库、网关、配置中心连通性

所有指标阈值由配置中心统一管控。

**7. 标准接口规范**

**7.1 健康探测接口**

* GET /health/live 存活探测
* GET /health/ready 就绪探测
* GET /health/business 业务健康探测

**7.2 运维查询接口**

* health/instance/list 获取全集群实例健康状态
* health/event/list 查询故障历史事件
* health/diagnose 实例一键诊断，输出详细故障原因

**8. 告警分级规范**

* degraded：WARN 预警，性能下降、资源偏高
* business\_fault：ERROR 故障，业务受损
* liveness\_fault / 节点失联：CRITICAL 紧急故障，集群风险

所有告警携带：实例 ID、节点、服务名、诊断信息、失败次数、时间链路。

**9. 权限与审计规范**

* 健康探测接口：公开可信访问
* 自愈配置、手动隔离、手动重启：需管理员 RBAC 权限
* 所有自愈、隔离、状态变更操作**永久审计留存**，带 TraceId 全链路追溯
