5. 所有备份自动生命周期管理，定时过期清理，杜绝存储无限膨胀
6. 恢复操作强制权限 + 审批，所有变更全程带 TraceId 永久审计

**2. 三级备份架构与调度策略**

**2.1 备份类型定义（强制固定）**

1. **full 全量快照**

* 用途：构建稳定数据基线，整库一致性镜像
* 默认周期：每周一次
* 特性：冻结快照时间点，保证事务一致性，无数据撕裂

1. **incremental 增量备份**

* 用途：记录基线之后变更数据，轻量化高频备份
* 默认周期：每日一次
* 依赖：必须基于最近一次成功全量快照基线

1. **wal 事务日志备份**

* 用途：实现毫秒级时间点恢复（PITR）
* 默认周期：每 5 分钟一次
* 价值：极大降低 RPO，可回溯至任意误操作时间点

**2.2 集群容灾指标基线**

* 仅全量 + 增量：RPO ≤ 24h
* 开启 WAL 日志备份：RPO ≤ 5min
* 标准恢复 RTO：单组件恢复 ≤ 10 分钟

**3. 备份一致性技术规范**

**3.1 一致性快照机制**

* 数据库组件：采用事务快照隔离，无锁一致性备份
* 业务存储组件：短时读写平滑窗口，保证文件结构完整
* **禁止裸拷文件、禁止非一致性快照落地**

**3.2 完整性校验强制规则**

* 每一份备份完成自动计算 SHA256
* 校验失败直接标记 invalid，触发 ERROR 告警
* 无效备份不参与恢复基线，自动隔离

**4. 备份存储分层与生命周期**

**4.1 双层灾备存储**

1. **本地备份池**：保留最近 3 份全量基线，用于快速本地恢复
2. **异地对象存储**：长期归档、跨机房灾备，核心集群双副本存储

**4.2 默认保留策略（可配置中心调参）**

* 全量快照：保留 4 周
* 增量备份：跟随所属全量基线生命周期，基线过期自动联动清理
* WAL 事务日志：保留 7 天

**4.3 自动清理规则**

* 定时任务扫描过期备份
* 校验备份无依赖、无恢复任务运行后清理
* 所有删除操作写入永久审计日志

**5. 数据恢复标准流程**

**5.1 三类恢复模式**

1. **全量恢复**：整库 / 整组件回退至指定快照基线
2. **局部恢复**：单项目、单工件、单记忆粒度精准恢复
3. **PITR 时间点恢复**：基于全量 + 增量 + WAL，精准恢复至任意时间戳

**5.2 恢复安全强制机制**

1. 生产恢复必须走 **审批流程**
2. 恢复前自动抓取当前现场快照，防止恢复失败无法回滚
3. 优先支持 **隔离环境预恢复验证**，验证通过再上线
4. 恢复完成自动数据对账：行数、哈希、索引数量、条目完整性校验

**6. 恢复演练规范**

* 系统季度自动触发灾备演练任务
* 演练环境与生产完全隔离
* 校验整条备份链路可用性、完整性、可恢复性
* 生成标准化演练报告，留存归档
* 演练失败触发集群 CRITICAL 告警，立即修复备份链路

**7. 标准 RPC 接口**

* backup/create 手动触发全量 / 增量备份
* backup/list 查询备份清单、状态、有效期
* backup/verify 手动触发备份完整性校验
* backup/restore/submit 提交数据恢复申请
* backup/expire/clean 手动清理过期备份
* backup/drill/start 启动灾备恢复演练

**8. 监控与告警分级**

* WARN：备份延迟、存储使用率超 70%、单条 WAL 断档
* ERROR：单次备份失败、备份校验失败
* CRITICAL：连续备份失败、异地灾备断连、基线损坏

所有告警携带 backupId、traceId、目标组件、故障详情。

**9. 权限与审计规范**

1. 备份查询：只读权限
2. 手动备份执行：运维权限
3. 数据恢复、演练、批量清理：管理员权限 + 审批流
4. 所有备份、校验、恢复、删除、演练操作**永久审计不可删除**
