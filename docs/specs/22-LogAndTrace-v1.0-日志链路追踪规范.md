**OpenSoulMate Log&Trace v1.0 全局日志与全链路追踪规范（定稿冻结）**

**0. 规范总览**

**0.1 定位**

本规范定义 OpenSoulMate 全生态**统一日志格式、日志分级、日志分类、脱敏规则、轮转策略、全链路 Trace 追踪体系**。

是整套系统**可观测、可排障、可审计、可运维**的底层基建。
统一解决：多模块日志混乱、无链路串联、排查困难、敏感信息泄露、日志泛滥刷屏、无法追踪跨 Agent 调用问题。

**0.2 核心作用**

1. 全链路串联：**用户会话 → ACP 交互 → A2A 跨 Agent 任务 → Tool 工具调用 → 状态变更 → 产物生成** 完整一条 Trace
2. 统一日志输出标准，所有 Agent、网关、服务、进程输出格式完全一致
3. 标准化日志脱敏，杜绝密钥、路径、隐私泄露
4. 日志分级管控，区分开发 / 生产输出粒度
5. 日志自动轮转、自动 GC，避免磁盘溢出
6. 支撑 MCP 运维监控、故障定位、任务审计

**0.3 层级依赖**

* 依赖协议：ACP v1.0、A2A v1.0、MCP v1.0
* 依赖规范：Session v1.0、State v1.0、Skill-Tool v1.0、Artifact v1.0
* 下游支撑：错误码规范、运维监控体系

**0.4 版本状态**

* 版本：v1.0 Final
* 状态：**冻结定稿，增量兼容，不破坏现有格式**
* 生效时间：2026-09-02

**1. 核心概念定义**

**1.1 链路标识体系（唯一贯穿全系统）**

1. **trace\_id**：全局唯一根链路 ID，**一次用户操作 / 一次会话全局唯一**
2. **span\_id**：单次子操作 ID，一个 trace 下多个 span（工具调用、子任务、状态更新）
3. **session\_id**：ACP 会话维度标识
4. **task\_id**：A2A 任务维度标识
5. **artifact\_id**：产物绑定标识

|  |
| --- |
| 核心规则：**所有日志必须携带至少 trace\_id，实现全局一键串联排查** |

**1.2 日志分类**

1. **协议日志**：ACP/A2A/MCP 报文收发、解析、路由日志
2. **业务日志**：Agent 推理、技能执行、工具调用、状态变更
3. **系统日志**：进程启停、资源告警、配置热更新、异常崩溃
4. **审计日志**：人工审批、权限校验、高危操作、产物变更（永久留存）

**2. 统一日志标准格式（强制全局）**

所有模块**禁止自定义日志格式**，必须输出标准 JSON 日志。

**2.1 标准日志 Schema**

|  |
| --- |
| json {  "timestamp": 1720000000000,  "level": "info",  "trace\_id": "trace-xxxx",  "span\_id": "span-xxxx",  "session\_id": "sess-xxxx",  "task\_id": "task-xxxx",  "agent\_id": "hermes",  "module": "skill-file-manager",  "msg": "文件读取执行成功",  "content": {},  "error": null,  "meta": {} } |

**2.2 字段释义与必填规则**

|  |  |  |
| --- | --- | --- |
| 字段 | 必填 | 说明 |
| timestamp | ✅ | 毫秒级时间戳，统一 UTC 时间 |
| level | ✅ | 日志级别固定枚举 |
| trace\_id | ✅ | 全局链路根 ID，**所有日志必带** |
| span\_id | ✅ | 子操作跨度 ID |
| session\_id | ❌ | ACP 会话操作必填 |
| task\_id | ❌ | A2A 任务操作必填 |
| agent\_id | ✅ | 当前输出日志的服务 / Agent ID |
| module | ✅ | 模块名：协议 / 技能 / 系统 / 工具名 |
| msg | ✅ | 简短可读描述，用于展示检索 |
| content | ✅ | 结构化详细内容，业务数据 |
| error | ❌ | 异常堆栈，仅错误日志携带 |
| meta | ✅ | 扩展标签、环境、版本、IP 等 |

**3. 日志级别规范（固定枚举）**

严格五级分级，禁止自定义级别：

* trace：超细粒度调试（仅开发环境，生产默认关闭）
* debug：模块调试信息、参数打印
* info：正常业务流程、状态变更、任务启停
* warn：非阻断异常、降级、重试、参数不规范
* error：功能失败、报错、进程异常、任务终止

**级别输出策略**

* 开发环境：全开（trace+debug+info+warn+error）
* 测试环境：info 及以上
* 生产环境：warn+error（可动态通过 MCP 调优）

**4. 全链路 Trace 绑定规则（核心）**

**4.1 链路生成规则**

1. **trace\_id 生成点**：ACP session/create 会话创建时生成全局唯一 TraceID，贯穿整个会话生命周期
2. **span\_id 生成点**：每一次工具调用、子任务委派、状态更新、协议请求自动生成新 Span

**4.2 链路传递规则**

1. ACP 会话：所有 Agent 操作复用**根 trace\_id**
2. A2A 子任务：子 Agent 继承主任务 trace\_id，生成独立 span\_id
3. 工具调用：复用当前会话 trace\_id，新增工具调用 span\_id
4. 产物生成：Artifact 元数据绑定当前 trace\_id、span\_id

**4.3 链路闭环**

通过 trace\_id 可一次性检索：

* 完整用户对话记录
* 所有工具调用记录
* 所有状态变更记录
* 所有子 Agent 协同日志
* 所有生成的 Artifact 产物

**5. 各类场景日志输出规范**

**5.1 ACP 协议日志**

* 会话创建 / 关闭、消息收发、审批请求、审批结果、状态更新
* 必须携带 session\_id + trace\_id

**5.2 A2A 协议日志**

* 任务创建、委派、执行、完成、失败、子任务联动
* 必须携带 task\_id + trace\_id

**5.3 工具 / 技能日志**

* 工具入参、执行开始、执行结束、耗时、结果、重试、超时
* 绑定 skill\_id /tool\_id

**5.4 状态机日志**

* status 变更、step 步进、progress 更新、快照生成、回滚操作
* 关联 state\_patch、state\_version

**5.5 异常日志规范**

error 字段固定结构：

|  |
| --- |
| json "error": {  "code": -32602,  "message": "参数非法",  "stack": "完整堆栈信息",  "retryable": false } |

**6. 日志脱敏安全规范（红线强制）**

所有日志输出前**自动脱敏**，禁止明文输出：

1. 所有 API Key、Token、密钥、授权凭证
2. 系统绝对路径、本地隐私目录
3. 账号、密码、私密配置
4. 内网地址、端口、敏感环境变量

脱敏规则：明文替换为 \*\*\*\*\*\*，保留字段结构，隐藏真实内容。

**7. 日志存储、轮转、GC 规范**

**7.1 存储格式**

* 统一：.log 标准 JSON 行日志（NDJSON）
* 单文件单天分割：2026-09-02.log

**7.2 轮转策略**

1. 按天轮转：每日凌晨自动分割新日志文件
2. 大小轮转：单文件最大 200MB，自动切分

**7.3 自动 GC 清理策略**

1. 普通业务日志：保留 7 天
2. 协议通信日志：保留 15 天
3. 审计高危操作日志：**永久留存**
4. 崩溃异常日志：永久留存

**8. MCP 管控联动规范**

1. MCP 支持**动态调整日志级别**，无需重启服务
2. MCP 提供日志检索接口：按 trace\_id /session\_id/task\_id /agent\_id 检索
3. MCP 统计日志指标：错误率、告警次数、工具失败统计
4. MCP 自动清理过期日志，磁盘水位监控告警

**9. 日志审计规范**

以下操作强制留存审计日志、不可删除：

1. 高危工具执行（删除、命令行、网络提交）
2. 人工审批通过 / 拒绝记录
3. 配置热更新、权限变更
4. Agent 进程启停、异常崩溃
5. 产物新增、修改、删除

**10. 红线禁止规则**

1. ❌ 禁止裸文本打印日志，**必须标准 JSON 结构**
2. ❌ 禁止日志输出敏感密钥、隐私路径、凭证
3. ❌ 禁止关键业务无日志、无链路标识
4. ❌ 禁止自定义日志级别、自定义字段
5. ❌ 禁止生产环境输出 trace/debug 冗余日志

**11. 兼容迁移规则**

* 历史零散日志、print 打印全部废弃
* 所有模块统一接入本日志体系
* 过渡期网关兼容旧日志，自动补全 trace\_id 结构化信息
