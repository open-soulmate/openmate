**OpenSoulMate ErrorCode v1.0 全局统一错误码注册表（定稿冻结）**

**0. 规范总览**

**0.1 定位**

本规范为 **OpenSoulMate 全系统唯一、统一、分层、无冲突** 的全局错误码标准。

统一解决：

* ACP/A2A/MCP 三套协议错误码混乱、重叠、不统一
* 前端无法自动解析错误、自动重试、自动提示
* 日志、监控、告警无法聚合统计故障类型
* 各 Agent、各模块自定义私有错误、对接成本极高

**0.2 核心价值**

1. **全域唯一编码**：协议层、业务层、系统层错误无冲突
2. **结构化错误信息**：可机器解析、可前端渲染、可监控统计
3. **标准化重试策略**：统一标记是否可重试
4. **统一文案**：人机展示文案统一，无口语化杂乱提示
5. **全链路匹配**：日志、状态机、Artifact、审计、监控完全对齐

**0.3 依赖体系**

* 依赖协议：ACP v1.0、A2A v1.0、MCP v1.0
* 依赖规范：Log&Trace v1.0、State v1.0、Skill-Tool v1.0

**0.4 版本状态**

* 版本：v1.0 Final
* 状态：**冻结定稿，字段永久兼容，仅增量新增**
* 生效时间：2026-09-02

**1. 错误码架构设计（四层域隔离）**

所有错误码 **按域分段、永不重叠**

|  |  |  |
| --- | --- | --- |
| 码段区间 | 归属域 | 说明 |
| -32600 ~ -32699 | **RPC 协议标准错误** | JSON-RPC2.0 原生标准，ACP/A2A/MCP 共用 |
| -32000 ~ -32099 | **ACP 人机会话域** | 会话、审批、前端交互、Agent 会话异常 |
| -32100 ~ -32199 | **A2A 多 Agent 协作域** | 任务委派、子任务、Agent 通信、Artifact 同步 |

|  |
| --- |
| 规则：**不同域绝不复用错误码，新增错误只能在对应域增量追加** |

**2. 统一错误报文标准（全局唯一结构）**

所有报错 **必须使用该结构输出**，禁止自定义格式

|  |
| --- |
| json {  "jsonrpc": "2.0",  "id": "xxx",  "error": {  "code": -32602,  "message": "参数非法",  "desc": "请求参数缺失或格式不合法，请检查入参结构",  "retryable": false,  "data": {}  } } |

**字段强制规范**

|  |  |  |
| --- | --- | --- |
| 字段 | 必填 | 作用 |
| code | ✅ | 全局唯一数字错误码 |
| message | ✅ | 短文案（前端弹窗 / 展示） |
| desc | ✅ | 详细技术描述（日志 / 排查 / 开发阅读） |
| retryable | ✅ | 是否可自动重试（布尔） |
| data | ✅ | 错误上下文、非法字段、超时时间、资源 ID 等 |

**7. 重试策略全局规则**

**7.1 自动重试条件**

仅 retryable: true 的错误允许：

* 网关自动重试
* 前端自动重连
* 任务自动重试恢复

**7.2 禁止重试场景**

* 参数错误
* 权限错误
* 人工拒绝
* 只读资源禁止修改

|  |
| --- |
| 以上场景重试无意义，系统直接终止任务 |

**8. 日志 & Trace 绑定规范**

1. **所有错误日志必须携带 error.code**
2. 监控告警按 code 聚合统计错误率
3. 链路追踪根据错误码标记故障节点
4. State 状态机 error 字段必须填充本标准结构

**9. 前端渲染规范**

1. 极简展示：error.message
2. 技术详情弹窗：error.desc + error.data
3. 根据 retryable 自动展示「重试按钮」

**10. 新增错误码规则（红线）**

1. 禁止占用已存在码值
2. 禁止跨域乱分配码段
3. 新增必须补齐：code /message/desc /retryable
4. 新增后必须同步更新本文档注册表

**11. 兼容迁移策略**

1. 所有旧版自由文本报错 **全部废弃**
2. 所有模块强制使用本结构化错误模型
3. 网关自动兼容旧报错，包装为标准错误结构
