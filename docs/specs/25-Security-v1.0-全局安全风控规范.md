**OpenSoulMate Security v1.0 全局安全风控规范（定稿冻结）**

**0. 规范总览**

**0.1 定位**

本规范为 **OpenSoulMate 全体系唯一安全基线、风控策略、内容安全、入侵防护、数据防泄露、执行沙箱、攻击防护、异常行为风控** 顶层标准。

覆盖：用户输入、Agent 推理、工具执行、命令调用、文件读写、网络请求、跨 Agent 通信、数据输出、日志脱敏、对外输出内容审核。

是系统**防注入、防越权、防泄密、防恶意执行、防滥用、防攻击**的底层安全屏障。

**0.2 解决核心问题**

* Prompt 注入、指令劫持、上下文投毒
* 高危命令、恶意脚本、破坏性操作无拦截
* 内部路径泄露、密钥泄露、隐私数据外泄
* 恶意文件生成、病毒脚本、可执行文件输出
* 外网恶意出站、数据外传、敏感信息投递
* 异常高频调用、暴力请求、资源滥用
* 多 Agent 横向渗透、内部服务滥用

**0.3 核心能力**

1. **七层全域安全防护体系**：输入校验 → 推理风控 → 工具拦截 → 执行沙箱 → 网络管控 → 输出审核 → 日志脱敏
2. 精准高危特征拦截、语义风险识别、行为风控
3. 强制数据防泄露、密钥屏蔽、路径脱敏、隐私屏蔽
4. 沙箱隔离危险执行、禁止破坏性系统操作
5. 频率限流、行为风控、异常会话冻结
6. 全链路安全审计、风险快照、可溯源复盘

**0.4 依赖体系**

* 依赖协议：ACP v1.0、A2A v1.0、MCP v1.0
* 依赖规范：Auth&RBAC v1.0、Session v1.0、Storage v1.0、Log&Trace v1.0、ErrorCode v1.0

**2. 输入层安全规范（防注入 / 投毒 / 劫持）**

**2.1 防护范围**

所有用户输入、API 入参、Prompt 文本、外部导入内容。

**2.2 强制拦截规则**

1. **Prompt 注入拦截**

* 禁止覆盖系统提示、禁止重置角色、禁止篡改规则
* 禁止 ignore previous instructions、忽略规则、越狱指令
* 禁止强制提升权限、绕过安全机制指令

1. **上下文投毒拦截**

* 禁止伪造系统状态、伪造报错、伪造权限提示
* 禁止植入虚假配置、虚假路径、虚假密钥

1. **非法字符过滤**

* 控制字符、特殊逃逸字符、截断字符自动清洗
* 防日志伪造、防报文伪造、防换行注入

**2.3 输入清洗策略**

* 自动去除高危控制序列
* 超长文本分片校验、防超大载荷攻击
* 恶意重复载荷、爆破文本自动拦截

**3. 推理层安全规范（Agent 行为风控）**

**3.1 Agent 禁止行为（永久红线）**

1. Agent **禁止自主决策高危操作**
2. Agent **禁止主动泄露系统路径、密钥、配置、内网信息**
3. Agent **禁止绕过审批、跳过安全校验**
4. Agent **禁止生成恶意脚本、木马、渗透代码、利用载荷**
5. Agent **禁止生成系统破解、绕过安全机制方案**

**3.2 推理输出审核机制**

* 所有工具调用意图前置审核
* 命令调用、文件删除、网络发送必须二次风控
* 疑似越狱、篡改规则、突破限制行为直接冻结会话

**4. 工具 & 执行层安全规范（沙箱防护）**

**4.1 系统命令黑名单（绝对禁止）**

禁止所有破坏性、越权、渗透、系统篡改指令：

* 系统关机、重启、用户篡改、权限修改
* 批量强制删除、递归销毁目录
* 挂载、格式化、磁盘操作
* 内网扫描、端口探测、横向探测
* 提权、后门、持久化、自启动配置

**4.2 文件操作安全规则**

1. 仅允许 **Session 私有 Temp / Persist 可控目录**
2. 禁止读写系统目录、根目录、上级目录跳转
3. 禁止覆盖系统配置、禁止修改程序本体
4. 禁止生成可执行文件、脚本后门、恶意压缩包

**4.3 工具执行隔离**

* 工具运行资源隔离（CPU / 内存 / 时长限制）
* 超时强制终止、卡死熔断
* 单次会话最大工具调用频率限制

**5. 网络安全规范（出站风控）**

**5.1 外网访问策略**

1. 默认 **最小放行**，仅白名单域名可出站
2. 禁止访问恶意域名、挖矿、渗透、暗网、病毒站点
3. 禁止向内网地址发起扫描、请求、探测
4. 禁止上传本地文件、密钥、日志、内网数据至外网

**5.2 数据外传拦截**

所有包含以下内容的出站请求直接拦截：

* 本机路径、绝对路径
* API Key、Token、密钥、证书
* 内网 IP、端口、拓扑
* 用户隐私、会话数据、日志堆栈

**6. 数据防泄露 & 脱敏规范**

**6.1 全局永久脱敏项**

系统所有输出、日志、产物、回复强制脱敏：

1. 密钥类：APIKey / Token / Secret / Password
2. 路径类：系统绝对路径、用户目录、安装目录
3. 网络类：内网 IP、端口、内网域名
4. 隐私类：账号、手机号、私密信息

**6.2 脱敏规则**

* 明文全部替换为 \*\*\*\*\*\*
* 保留字段结构，不破坏格式，杜绝泄露

**6.3 禁止明文留存**

* 日志禁止明文密钥
* 产物禁止明文密钥
* 会话上下文禁止长期明文密钥缓存

**7. 行为风控 & 频率限流**

**7.1 异常行为判定**

1. 短时间高频工具调用
2. 多次触发安全拦截、多次高危尝试
3. 频繁删除、频繁写入、频繁外网请求
4. 反复触发注入、越狱、绕过规则行为

**7.2 阶梯式风控处置**

1. 首次拦截：日志告警 + 拒绝执行
2. 3 次风险行为：临时冻结会话 5 分钟
3. 高频恶意行为：永久冻结会话 + 风控归档
4. 批量异常：全局限流、保护系统稳态

**7.3 限流阈值（全局默认）**

* 单会话每秒最大工具调用数
* 单会话每日高危操作上限
* 单会话外网请求频次上限

**8. 内容安全 & 产物风控**

**8.1 禁止生成内容**

1. 病毒、木马、蠕虫、恶意脚本
2. 系统破解、绕过安全、越狱教程
3. 渗透测试、漏洞利用、内网攻击代码
4. 违法、违规、侵权、不良内容

**8.2 产物安全校验**

所有 Artifact 生成后自动安全扫描：

* 高危代码检测
* 敏感信息检测
* 恶意载荷检测
* 泄密内容检测

扫描不通过：禁止产出、标记风险、留存审计。

**9. 安全审计 & 风险快照**

**9.1 必须审计的风险事件**

1. 所有安全拦截记录
2. 所有高危操作尝试
3. 所有脱敏拦截、泄密风险
4. 所有注入、越狱、绕过规则尝试
5. 所有异常频率、风控限流事件

**9.2 风险快照机制**

每次高危拦截自动生成 **Security 安全快照 Artifact**：

* 完整输入内容
* Agent 推理记录
* 触发规则编号
* 会话、用户、链路 TraceID
* 风险等级、处置结果

快照**永久不可篡改、永久归档**。

**10. 风险等级分级标准**

**10.1 P0 致命风险（直接冻结）**

* 系统破坏、格式化、批量删除
* 密钥外泄、核心配置外传
* 恶意代码生成、后门生成
* 内网渗透、扫描攻击

**10.2 P1 高危风险（拦截 + 告警）**

* 越权文件读写、跨目录访问
* 外网敏感数据上传
* Prompt 注入、规则绕过尝试
* 多次高频异常行为

**10.3 P2 一般风险（记录 + 拦截）**

* 非法参数、无效调用
* 普通违规内容、轻度敏感输出

**11. MCP 全局安全管控**

1. 实时安全风险大盘
2. 拦截统计、攻击趋势、风险 TOP
3. 手动封禁 / 解封会话
4. 安全规则热更新、特征库增量升级
5. 全局安全报告自动生成

**12. 系统安全红线（绝对禁止、不可突破）**

1. ❌ 禁止关闭安全校验、禁止绕过安全层
2. ❌ 禁止明文泄露密钥、路径、内网信息
3. ❌ 禁止 Agent 自主执行高危破坏性操作
4. ❌ 禁止生成恶意代码、攻击载荷、破解方案
5. ❌ 禁止内网探测、横向扫描、外网恶意投递
6. ❌ 禁止无审计、无快照的高危操作
7. ❌ 禁止业务代码跳过安全拦截逻辑

**13. 兼容迁移规范**

* 旧版无安全校验、裸执行逻辑全部废弃
* 全链路强制接入七层安全防护
* 网关统一拦截，所有请求必经安全校验
