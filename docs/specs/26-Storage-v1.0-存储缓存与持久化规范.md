**1. 核心存储分层模型（强制四层）**

全系统所有数据**必须归入以下四层之一**，禁止自定义存储模式。

**1.1 L1 内存缓存（Runtime Cache）**

* 作用：运行时高速读写、会话临时变量、状态缓存
* 特性：断电丢失、重启清空、毫秒级访问
* 承载数据：Session 上下文、State 运行时树、临时计算结果
* 归属：绑定 session\_id /agent\_id

**1.2 L2 临时磁盘存储（Temp）**

* 作用：单次会话临时文件、中间产物、编译缓存、解压临时目录
* 特性：会话销毁自动清理、短期留存
* 生命周期：跟随 Session 生命周期
* 自动 GC：会话关闭 / 冻结超时 强制清空

**1.3 L3 本地持久化存储（Persistent）**

* 作用：配置、快照、历史状态、会话记录、日志、技能缓存
* 特性：永久落地、重启不丢失、版本可追溯
* 核心数据：State 快照、Session 元数据、本地 Artifact、配置文件

**1.4 L4 远端对象归档（Archive）**

* 作用：最终产物归档、长期审计、超大文件备份
* 特性：高可靠、不可篡改、永久留存
* 承载数据：最终产出文档、报告、审计记录、故障快照

**2. 全局统一目录结构（全站唯一、强制固定）**

所有 Agent、网关、服务 **禁止自定义目录**，严格遵循全局目录规划。

|  |
| --- |
| Plain Text ./data  ├── /runtime # L1 内存运行时数据落地目录  ├── /temp # L2 全局临时文件（自动GC）  │ └── /{session\_id}  ├── /persist # L3 本地持久化根目录  │ ├── /session # 会话持久化  │ ├── /state # 状态机快照  │ ├── /artifact # 本地工件存储  │ ├── /config # 全局热配置  │ └── /log # 结构化日志持久化  └── /archive # L4 归档备份目录  └── /{yyyy-mm-dd} |

**目录权限规则**

1. /runtime /temp：**可读写、自动清理**
2. /persist：**只读保护，仅系统写入**，禁止业务随意删除
3. /archive：**只读归档、禁止修改**

**3. 四层存储详细规范**

**3.1 L1 内存缓存规范**

**3.1.1 存储内容**

* 当前会话 Σ State 完整状态树
* 技能运行时临时上下文
* 工具调用临时参数缓存
* A2A 任务运行时队列

**3.1.2 淘汰策略**

1. 会话销毁 → 立刻清空对应缓存
2. 会话冻结 → 降级缓存、保留快照
3. 内存水位超限 → LRU 淘汰最久未使用会话缓存

**3.1.3 约束**

* 禁止缓存持久化关键数据
* 所有内存状态变更**必须落地快照至 L3**

**3.2 L2 临时磁盘存储规范**

**3.2.1 存储内容**

* 工具执行中间文件
* 解压 / 编译 / 渲染临时产物
* 单次任务临时输出
* 网络下载临时缓存

**3.2.2 生命周期**

* **完全绑定 Session**
* Session active：保留
* Session frozen 超时：自动清空
* Session destroyed：强制递归删除目录

**3.2.3 GC 规则**

* 单日临时文件凌晨全量巡检清理
* 超过 24 小时未关联活跃会话的临时目录强制删除

**3.3 L3 本地持久化规范（系统核心）**

**3.3.1 存储内容（系统级关键数据）**

* 所有 Session 元数据
* State 每版快照文件
* 本地 Artifact 产物
* 系统配置、热更新配置
* 结构化日志、审计记录

**3.3.2 写入策略（强一致性）**

1. **先写磁盘，后更新内存**
2. 状态重大变更必须同步落地快照
3. 配置修改双写：临时校验写入成功后覆盖正式配置
4. 禁止内存更新成功、磁盘写入失败的不一致状态

**3.3.3 保留策略**

* 会话数据：保留 30 天
* 状态快照：保留最近 10 版 + 每日快照
* 日志：遵循 Log&Trace 规范分级保留
* 配置：所有变更自动备份历史版本

**3.4 L4 远端归档规范**

**3.4.1 存储内容**

* 最终交付产物
* 任务完整报告
* 故障复盘快照
* 高危操作审计存档

**3.4.2 特性**

* 写入即只读
* 禁止覆盖、禁止删除
* 按日期分目录归档
* 永久留存，用于合规审计

**4. 缓存策略规范**

**4.1 全局缓存原则**

1. **读多写少优先缓存**
2. **动态数据禁止长缓存**
3. **状态类数据快照缓存 + 增量更新**

**4.2 缓存失效机制**

* 主动失效：State 更新、Artifact 更新、配置更新主动清空对应缓存
* 被动失效：TTL 超时、LRU 淘汰、会话销毁

**4.3 禁止缓存场景**

* 高危工具执行结果
* 动态密钥、凭证、令牌
* 实时系统资源数据
* 未落地持久化的关键状态

**5. 文件读写安全规范（红线）**

1. **所有文件操作必须绑定 session\_id /trace\_id**，日志可追溯
2. 禁止跨会话读写对方 /temp /persist 私有目录
3. 禁止业务代码直接删除 /persist 核心数据
4. 所有写操作必须校验磁盘水位，避免溢出
5. 所有输出产物**必须封装为 Artifact**，禁止裸文件散落

**6. 磁盘水位与过载保护**

**6.1 水位阈值**

* 80%：告警、禁止新增大文件写入
* 90%：自动触发 GC、清理过期临时、过期日志
* 95%：只读保护，仅允许日志落地与快照紧急留存

**6.2 MCP 管控能力**

* 实时磁盘使用率监控
* 自动 GC 调度
* 手动一键清理临时资源
* 存储配额按用户 / 会话隔离

**7. 数据一致性保障**

1. 会话重启：加载 L3 最新 State 快照恢复完整上下文
2. 进程崩溃：磁盘留存最后一致快照，无脏数据
3. 多 Agent 协同：产物统一存入 Artifact，避免多端文件冲突
4. 配置热更新：双文件原子替换，无损坏窗口
