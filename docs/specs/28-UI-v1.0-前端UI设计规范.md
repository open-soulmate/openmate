# OpenSoulMate v1.0 前端UI设计规范

> 基于 openface 组件体系 + 现有 CSS 变量 + 页面模式提炼。
> 生效时间：2026-09-02 | 状态：定稿冻结

---

## 1. 设计系统总览

### 1.1 技术栈
- **框架**: Next.js 16 + React 19 + TypeScript
- **UI组件库**: `@opensoulmate/openface` — 统一组件、Token、布局
- **样式**: Tailwind CSS 4 + CSS Variables（dark mode优先）
- **状态管理**: Zustand (`useAppStore`)
- **图标**: Lucide React
- **工具函数**: `cn()` (clsx + twMerge)

### 1.2 设计原则
1. **组件不重复** — openface已有的组件绝不手写，统一import
2. **三栏布局标准** — sidebar + MainPanel + DetailPanel/WorkspacePanel
3. **响应式优先** — 移动端overlay面板+三态切换，不砍功能
4. **暗色主题为主** — light/purple主题可切换，dark为默认

## 3. 布局体系

### 3.1 AppShell 标准布局

```
┌─────────────────────────────────────────┐
│ TopBar (48px) — logo + 名称 + 设置按钮    │
├────────┬────────────────────┬───────────┤
│        │                    │           │
│ Left   │   MainPanel        │ Right     │
│ Panel  │   (主内容区)        │ Panel     │
│ (280px)│                    │ (320px)   │
│        │                    │           │
├────────┴────────────────────┴───────────┤
│ BottomBar (48px) — 用户头像 + 导航 + 自定义│
└─────────────────────────────────────────┘
```

### 3.2 PageLayout桥接层（重要）

`PageLayout`是OpenMate对openface `MainPanel`的桥接封装，**所有页面必须用`PageLayout`而不是裸`MainPanel`**：

```tsx
// ✅ 正确 — 用PageLayout
import { PageLayout } from "@/components/page-layout";
<PageLayout title="..." icon={...}>...</PageLayout>

// ❌ 错误 — 直接用MainPanel（toggle折叠不生效）
import { MainPanel } from "@opensoulmate/openface";
<MainPanel title="..." icon={...}>...</MainPanel>
```

**原因**：`PageLayout`桥接了`useSidebar().toggleSidebar`和`appStore.toggleRightPanel`到openface的`MainPanel`，使动态岛toggle按钮能正确折叠sidebar和workspace。裸`MainPanel`不感知OpenMate的状态管理。

```tsx
// PageLayout源码（page-layout.tsx）
export function PageLayout(props: MainPanelProps) {
  const { open: sidebarOpen, toggleSidebar } = useSidebar();
  const toggleRightPanel = useAppStore((s) => s.toggleRightPanel);
  return (
    <MainPanel
      {...props}
      sidebarOpen={sidebarOpen}
      onToggleSidebar={toggleSidebar}
      onToggleRightPanel={toggleRightPanel}
    />
  );
}
```

### 3.3 MainPanel内部结构

```
┌──────────────────────────────────────┐
│ MainHeader (banner)                  │
│ [☰] [icon] Title [badge] [actions] [◫] │
├──────────────────────────────────────┤
│                                      │
│         children (主内容)             │
│                                      │
└──────────────────────────────────────┘
```

MainPanel内置MainHeader，通过props控制：
- `title/icon/badge` — 默认banner内容
- `headerActions` — banner右侧按钮
- `header` — 完全覆盖默认banner
- `showSidebarToggle/showWorkspaceToggle` — 折叠按钮显隐
- `workspace` — 直接注入右panel内容（可选，通常用setPageWorkspace）

### 3.3 页面注册模式

**所有页面必须使用openface标准三栏注册，禁止自建布局容器。**

```tsx
// ✅ 正确 — 使用 setPageSidebar + MainPanel + setPageWorkspace
function MyPage() {
  const setPageSidebar = useAppStore(s => s.setPageSidebar);
  const setPageWorkspace = useAppStore(s => s.setPageWorkspace);

  // 注册左侧sidebar
  useEffect(() => {
    setPageSidebar(<LeftPanel items={...} renderItem={...} />);
    return () => setPageSidebar(null);
  }, []);

  // 注册右侧DetailPanel（点击触发）
  useEffect(() => {
    if (selected) {
      setPageWorkspace(<DetailPanel title={...} sections={...} />);
    } else {
      setPageWorkspace(null);
    }
    return () => setPageWorkspace(null);
  }, [selected]);

  // MainPanel内容（中间区域）
  return (
    <div className="px-3 lg:px-6 py-4 lg:py-6 h-full overflow-y-auto">
      {/* 页面内容 */}
    </div>
  );
}

// ❌ 错误 — 自建flex布局、自建左右面板
function MyPage() {
  return (
    <div className="flex h-full">  // 禁止
      <div className="w-80">...</div>  // 禁止自建sidebar
      <div className="flex-1">...</div>
    </div>
  );
}
```

### 3.3 响应式断点

| 断点 | 宽度 | 布局行为 |
|------|------|---------|
| 移动端 | <768px | sidebar/DetailPanel为overlay浮层 |
| 平板 | 768-1024px | sidebar可折叠 |
| 桌面 | >1024px | 三栏完整显示 |

### 4.2 页面内自定义组件（允许手写）

以下组件openface不提供，可手写，但必须遵循token体系：

| 组件 | 规范 |
|------|------|
| 统计卡片 | `rounded-xl border bg-card p-3 lg:p-4`，数值用`text-lg lg:text-2xl font-bold` |
| 状态Badge | `text-[10px] px-1.5 py-0.5 rounded-full`，颜色用语义色 |
| 搜索框 | `rounded-lg border border-border bg-muted text-xs lg:text-sm` |
| 卡片网格 | `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-2 lg:gap-4` |
| 列表项 | `rounded-xl border bg-card p-3 lg:p-4 transition-all hover:border-primary/30 cursor-pointer` |
| 空状态 | 居中图标(48px opacity-30) + 文字 |

### 4.3 禁止事项

| 禁止 | 原因 |
|------|------|
| 自建`<div className="flex h-full">`布局 | 破坏AppShell三栏体系 |
| 自建sidebar容器 | 用`setPageSidebar`注册 |
| 自建right panel容器 | 用`setPageWorkspace`注册 |
| 手写`LeftPanel`/`RightPanel` | 统一用openface组件 |
| 硬编码颜色值 | 用CSS变量/token |
| 手写滚动条样式 | globals.css统一管理 |
| `PageLayout`包装openface页面 | openface自带MainPanel |

## 5. 主题体系

### 5.1 支持的主题

| 主题 | 主色 | 默认 |
|------|------|------|
| `dark` | `#7c3aed` (紫) | ✅ 默认 |
| `light` | `#6366f1` (靛) | |
| `purple` | 深紫色调 | |

### 5.2 主题切换

```tsx
import { useTheme } from '@opensoulmate/openface';

const { theme, setTheme } = useTheme();
setTheme('light'); // 'dark' | 'light' | 'purple'
```

### 5.3 CSS变量主题切换机制

主题通过在`<html>`上添加class（`.light`、`.purple`）切换CSS变量值。所有颜色引用`var(--color-xxx)`，自动响应主题变化。

## 7. 交互规范

### 7.1 页面生命周期

```
页面挂载 → useEffect注册setPageSidebar → 页面内容渲染
用户点击 → setSelectedXxx → useEffect注册setPageWorkspace → DetailPanel打开
页面卸载 → return () => setPageSidebar(null) + setPageWorkspace(null)
```

### 7.2 状态管理

| 状态 | 管理方式 |
|------|---------|
| 全局UI状态（sidebar/workspace） | `useAppStore` (Zustand) |
| 页面局部状态 | `useState` |
| 异步数据 | `useCallback` + `fetch` |
| 主题 | `useTheme()` |

### 7.3 Loading & Empty状态

- **Loading**: 居中文字"加载中..."或skeleton
- **Empty**: 居中图标(48px, opacity-30) + 说明文字
- **Error**: 红色文字 + 重试按钮

---

## 8. 动画规范

- **过渡**: `transition-colors` (hover效果)、`transition-all` (卡片选中)
- **时长**: 默认200ms
- **禁止**: 大面积动画、阻塞交互的动画
