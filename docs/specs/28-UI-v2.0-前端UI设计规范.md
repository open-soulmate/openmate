# OpenSoulMate v2.0 前端UI设计规范

> 整合 HyperOS4 设计语言 + Web/桌面端/移动端三端适配
> 生效时间：2026-09-05 | 状态：定稿
> 前版本：v1.0 (2026-09-02)
> 变更：新增三端适配、Design Token 体系、HyperOS 设计语言、移动端规范

---

## 1. 设计系统总览

### 1.1 技术栈
- **框架**: Next.js 16 + React 19 + TypeScript
- **UI组件库**: `@opensoulmate/openface` — 统一组件、Token、布局
- **样式**: Tailwind CSS 4 + CSS Variables（dark mode优先）
- **状态管理**: Zustand (`useAppStore`)
- **图标**: Lucide React（禁止 emoji，风格统一）
- **工具函数**: `cn()` (clsx + twMerge)
- **桌面端**: Tauri 2.x（与 Web 共用 UI 代码）
- **移动端**: 响应式 / Tauri Mobile

### 1.2 设计原则（整合 HyperOS4）
1. **三层色彩体系** — 70% 背景层 + 20% 次级层 + 10% 强调层
2. **语义色固定含义** — 蓝=选中/链接、绿=成功、黄=警告、红=错误
3. **文字三级层级** — 主要100%、次要60%、辅助40%
4. **不纯黑不纯白** — 暗色背景 #0a0a0f ~ #1a1a2e，亮色背景 #faf8f5 ~ #f5f0eb
5. **组件不重复** — openface已有的组件绝不手写，统一import
6. **三栏布局标准** — sidebar + MainPanel + DetailPanel/WorkspacePanel
7. **响应式优先** — 移动端overlay面板+三态切换，不砍功能
8. **暗色主题为主** — light/purple主题可切换，dark为默认

### 1.3 三端适配总览

| 维度 | 移动端 | 网页端/桌面端 |
|---|---|---|
| 最小点击目标 | 48px（手指） | 32px（鼠标） |
| 安全区边距 | ≥16px | ≥8px |
| 字号基数 | 16px | 14px |
| 圆角风格 | 偏大（柔润） | 适中（专业） |
| 布局模式 | 单列/底部Tab栏 | 多面板/左侧边栏 |
| 导航方式 | 底部Tab栏 | 左侧边栏 |
| 交互方式 | 触摸+手势 | 鼠标+键盘 |
| 信息密度 | 低（呼吸感） | 高（效率优先） |

## 2. Design Token 体系

### 2.1 字体 Token

```css
--font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans SC", sans-serif;

--transition-slow: 300ms ease;
```

### 2.6 颜色 Token（三层体系）

#### 背景层（70%）

| Token | 用途 |
|---|---|
| `--color-background` | 页面底色 |
| `--color-foreground` | 正文文字 |

#### 次级层（20%）

| Token | 用途 |
|---|---|
| `--color-card` / `--color-surface` | 卡片/面板背景 |
| `--color-sidebar` | 侧边栏背景 |

| `--color-surface-hover` | 悬停态 |
| `--color-border` | 边框 |

#### 强调层（10%）

| Token | 用途 |
|---|---|
| `--color-primary` | 主色（选中/激活/链接） |
| `--color-ring` | 聚焦环 |

#### 文字三级层级

| Token | 透明度 | 用途 |
|---|---|---|
| `--color-text-primary` | 100% | 主要文字 |
| `--color-text-secondary` | 60% | 次要文字 |
| `--color-text-tertiary` | 40% | 辅助文字 |

#### 语义色

| Token | 含义 | 示例（深海静谧） |
|---|---|---|
| `--color-success` | 成功/正常 | #9ece6a |
| `--color-warning` | 警告 | #e0af68 |
| `--color-error` | 错误/危险 | #f7768e |
| `--color-info` | 信息 | #7dcfff |
| `--color-destructive` | 危险操作 | 继承 error |

## 3. 组件规范

### 3.1 消息气泡

```css
/* 用户消息 — 右对齐，主色调 */
.msg-user {
  background: var(--color-primary);
  color: white;
  border-radius: var(--radius-bubble) var(--radius-bubble) var(--radius-xs) var(--radius-bubble);
  max-width: 70%;
  padding: var(--space-2) var(--space-3);
}

/* AI 消息 — 左对齐，表面色 */
.msg-ai {
  background: var(--color-surface);
  color: var(--color-text-primary);
  border-radius: var(--radius-bubble) var(--radius-bubble) var(--radius-bubble) var(--radius-xs);
  max-width: 80%;
  padding: var(--space-2) var(--space-3);
}

/* 系统消息 — 居中，小字 */
.msg-system {
  color: var(--color-text-secondary);
  font-size: var(--text-caption);
  text-align: center;
  padding: var(--space-2) 0;
}
```

### 3.2 侧边栏（网页端/桌面端）

```css
.sidebar {
  width: 280px;
  background: var(--color-sidebar);
  border-right: 1px solid var(--color-border);
  padding: var(--space-3) 0;
}
.sidebar-item {
  padding: var(--space-2) var(--space-4);
  border-radius: var(--radius-nav);
  cursor: pointer;
}
.sidebar-item.active {
  background: var(--color-primary-subtle);
  color: var(--color-primary);
}
```

### 3.3 底部导航栏（移动端）

```css
@media (max-width: 768px) {
  .sidebar {
    position: fixed; bottom: 0; left: 0; right: 0;
    width: 100%; height: 56px;
    display: flex; flex-direction: row; justify-content: space-around;
    border-right: none; border-top: 1px solid var(--color-border);
    padding-bottom: env(safe-area-inset-bottom);
  }
}
```

### 3.4 弹窗/模态框

- **桌面端**：居中弹窗，`border-radius: var(--radius-lg)`，`max-width: 480px`
- **移动端**：底部 Sheet，`border-radius: var(--radius-sheet) var(--radius-sheet) 0 0`，`slideUp` 动画

### 3.5 按钮

```css
.btn-primary {
  background: var(--color-primary);
  border-radius: var(--radius-sm);
  padding: var(--space-2) var(--space-4);
  min-height: 32px;  /* 移动端 48px */
  min-width: 64px;   /* 移动端 48px */
  font-size: var(--text-body);
  font-weight: 500;
}
```

### 3.6 卡片

```css
.card {
  background: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-md);
  padding: var(--space-4);
}
```

## 4. 交互规范

### 4.1 桌面端交互

- **Hover**: 所有可交互元素必须有 hover 状态，按钮微上浮 `translateY(-1px)`
- **Focus**: `:focus-visible` 显示 `2px solid var(--color-primary)` 轮廓
- **滚动条**: 6px 宽，自动隐藏，hover 时显示

### 4.2 移动端交互

- **触摸反馈**: `:active` 时 `opacity: 0.7` + `scale(0.98)`，禁用 hover
- **手势**: 左滑删除 `touch-action: pan-y`，下拉刷新 `overscroll-behavior-y: contain`
- **键盘弹出**: 输入框 `position: sticky; bottom: env(keyboard-inset-height, 0px)`
- **滚动条**: 隐藏但保留滚动 `-webkit-scrollbar: display: none`

### 4.3 安全区

| 场景 | 移动端 | 网页端/桌面端 |
|---|---|---|
| 内容区边距 | ≥16px | ≥8px |
| 弹窗/模态框 | ≥20px | ≥16px |
| 卡片内边距 | ≥16px | ≥12px |
| 按钮最小高度 | 48px | 32px |
| 底部安全区 | `env(safe-area-inset-bottom)` | — |

### 5.2 主题切换机制

- 切换方式：`applyTheme(themeId)` → 修改 `document.documentElement` 的 class
- 暗色主题：添加 `dark` + `theme-xxx` 类
- 亮色主题：只添加 `theme-xxx-light` 类
- 持久化：`localStorage.setItem("openmate-theme", themeId)`

### 5.3 自定义主题

用户可通过设置页面的颜色编辑器自定义9个颜色值，存储在 localStorage。

## 6. 响应式断点

```css
--breakpoint-sm: 640px;    /* 手机横屏 */
--breakpoint-md: 768px;    /* 平板 */
--breakpoint-lg: 1024px;   /* 小桌面 */
--breakpoint-xl: 1280px;   /* 标准桌面 */
--breakpoint-2xl: 1536px;  /* 大桌面 */
```

### 布局规则
- **≥1024px**: 侧边栏 + 主内容区 + 可选右面板
- **768-1024px**: 侧边栏折叠为图标模式
- **<768px**: 侧边栏变底部Tab栏，全屏模式

## 7. HyperOS4 设计语言适配

### 7.1 已采纳的 HyperOS 原则

| HyperOS 原则 | OpenMate 实施 |
|---|---|
| 三层色彩体系 70/20/10 | ✅ `--color-background` / `--color-surface` / `--color-primary` |
| 语义色固定含义 | ✅ `--color-success/warning/error/info` |
| 文字三级层级 | ✅ `--color-text-primary/secondary/tertiary` |
| 圆角=尺寸1/4 | ✅ `--radius-xs/sm/md/lg` |
| 不纯黑不纯白 | ✅ 所有主题均避免纯 #000/#fff |

### 7.2 移动端专属适配

| HyperOS 特性 | CSS 实施 |
|---|---|
| 柔光玻璃 | `backdrop-filter: blur(12px)` 仅弹窗使用 |
| 圆润圆角 | 移动端 `--radius-lg: 20px` |
| 大触摸目标 | 移动端按钮 `min-height: 48px` |
| 底部安全区 | `env(safe-area-inset-bottom)` |

### 7.3 未采纳（桌面端不适合）

| HyperOS 特性 | 原因 |
|---|---|
| MiSans 字体 | 桌面端用 Inter 更通用 |
| 重度毛玻璃 | 桌面端信息密度高，降低可读性 |
| 全屏沉浸 | 桌面端多面板布局 |

## 8. 开发规则

### 8.1 CSS 变量使用规则

1. **必须使用 Token** — 禁止硬编码颜色/字号/间距值
2. **新增组件必须适配三端** — 使用 `@media (max-width: 768px)` 覆盖
3. **主题变量分层** — 颜色放主题块，结构 token 放 `:root` / `@theme`

### 8.2 图标规则

- **统一使用 Lucide React** — 禁止 emoji
- **风格一致** — 同一页面图标粗细统一

### 8.3 强制注释

所有代码输出哪怕一行必须带注释。
