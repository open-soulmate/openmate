# 用户使用手册

> 面向普通用户：如何使用 OpenMate 的核心功能

---

## 快速开始

### 1. 登录

打开浏览器访问 `http://localhost:3002`，使用管理员账号登录。

### 2. 创建 Agent

1. 进入 **设置** 页面
2. 点击 **Agent 管理**
3. 点击 **新建 Agent**
4. 填写 Agent 名称、角色、模型配置
5. 保存

### 3. 开始对话

1. 在左侧边栏选择 Agent
2. 点击 **新建会话**
3. 在输入框输入消息
4. Agent 会实时流式回复

---

## 核心功能

### 多 Agent 对话

- 每个 Agent 有独立的会话列表
- 切换 Agent 不影响其他会话
- 每个 Agent 可配置不同的模型

### AI 群组

1. 进入 **群组** 页面
2. 点击 **创建群组**
3. 添加 Agent 成员（顾问/执行者/审核者）
4. 输入任务描述
5. 点击 **发起讨论**
6. Agent 们会自动讨论、分工、执行、评分

### 模型路由器

1. 进入 **设置** → **模型路由**
2. 选择路由模式：
   - **Cost**：优先便宜模型
   - **Balance**：性价比最优
   - **Intelligence**：优先最强模型
   - **Auto**：根据任务复杂度自动选择

### 主题切换

1. 进入 **设置** → **主题**
2. 选择预设主题（7套可选）
3. 或点击 **自定义** 自行调整颜色

### 思考过程

- Agent 回复时会显示思考过程（ThinkingBlock）和工具调用（ToolCallBlock）
- 点击标题可展开/折叠
- 点击顶部 🧠 按钮可全局开关

---

## 群组功能详解

### 创建群组

1. 点击左侧 **+** 按钮
2. 输入群组名称和描述
3. 添加 Agent 成员：
   - **Advisor（顾问）**：分析任务、提出方案
   - **Executor（执行者）**：认领任务、执行
   - **Verifier（审核者）**：审核结果、评分

### 发起讨论

1. 选择群组
2. 点击输入框旁的 💬 按钮
3. 输入任务描述和约束条件
4. 点击 **开始讨论**
5. Agent 会按角色顺序自动发言（3轮）
6. 讨论结束后可查看评分结果

### 取消讨论

讨论进行中时，点击红色 ⏹ 按钮取消。
